## 시작 전: 제품 마케팅 컨텍스트 확인

`.claude/product-marketing.md`가 있으면 먼저 읽고 시작한다. 이미 파악된 제품/고객/포지셔닝 정보는 다시 묻지 않는다. 파일이 없으면 `/marketing-product-marketing` 먼저 실행 권장.

---
고객이 실제로 무엇을 생각하고, 느끼고, 말하는지 파악합니다.

**시작 전 확인사항**:

1. **목표가 무엇인가?** (메시지 개선? 페르소나 작성? 이탈 원인 파악? 신규 기획?)
2. **보유한 자료가 있는가?** (인터뷰 기록, 설문 결과, 고객 후기, 상담 내용 등)
3. **어떤 고객 세그먼트를 분석할 것인가?** (전체? 특정 플랜? 이탈 고객?)
4. **어떤 결과물이 필요한가?** (페르소나, VOC 인사이트 요약, 카피용 표현 목록 등)

## 분석 모드

### 모드 1: 보유 자료 분석

인터뷰 녹취, 설문 응답, CS 문의, 후기 등 기존 데이터를 가지고 있을 때.

**자료 유형별 분석 포인트**

| 자료 유형 | 주목할 것 |
|-----------|-----------|
| 고객 인터뷰/영업 통화 | 구매 전 고민, 대안 탐색, 성공 기준, 실제 쓰는 표현 |
| 설문 결과 | 주관식 응답 (객관식보다 신호 강함), 세그먼트별 차이 |
| CS 문의/채팅 | 반복 불만, 혼란 지점, "이런 기능 없나요?" |
| 이탈/해지 인터뷰 | 가격인지 기능인지 타이밍인지 구분 필수 |
| NPS 응답 | 불만족(6이하) + 이유 조합이 가장 높은 신호 |

**추출 프레임워크**

각 자료에서 아래 5가지를 뽑는다:

1. **핵심 과업 (Jobs to Be Done)**: 고객이 달성하려는 결과
   - 기능적: 실제 하려는 일
   - 감정적: 어떤 기분이 되고 싶은지
   - 사회적: 주변에 어떻게 보이고 싶은지

2. **불편함/불만**: 현재 상황에서 답답하거나 부족한 것

3. **트리거 이벤트**: 솔루션을 찾기 시작한 계기 (팀 확장, 실수 발생, 경쟁사 변화 등)

4. **원하는 결과**: 성공한 모습 — 고객의 말 그대로

5. **실제 쓰는 표현**: 고객이 직접 쓴 단어와 문장 (카피 작성에 직접 활용)

### 모드 2: 온라인 리서치

자료가 없을 때 온라인에서 직접 고객 목소리를 수집한다.

**ICP 유형별 주요 출처**

| 타겟 | 우선 출처 |
|------|-----------|
| B2B / 중소기업 | 네이버 블로그, 유튜브 댓글, 카카오오픈채팅, 직장인 커뮤니티 |
| 스타트업 / 창업자 | 스타트업 커뮤니티, 블라인드, 링크드인 |
| 일반 소비자 | 네이버 카페, 쿠팡/스마트스토어 후기, 유튜브 댓글 |
| 전문직 | 업종별 카페·커뮤니티, 학회 자료, 오픈채팅 |

**수집 시 템플릿**

각 발견에 대해 아래를 기록한다:
```
출처: [플랫폼, URL, 날짜]
원문 인용: "[정확한 표현]"
맥락: 어떤 상황에서 나온 말인가?
감정: 긍정 / 부정 / 중립 / 답답함
주제 태그: 불만 / 트리거 / 원하는결과 / 대안 / 언어
고객 프로필 힌트: 직책, 회사 규모, 업종 추정
```

## 인사이트 종합

여러 자료를 분석한 후 아래 형식으로 정리한다:

```
## 주요 테마 (빈도 × 강도 순)

### 테마 1: [이름]
요약: [1~2문장]
빈도: [N]개 자료에서 등장
강도: 높음 / 중간 / 낮음
대표 인용:
- "[정확한 표현]" — [출처, 날짜]
- "[정확한 표현]" — [출처, 날짜]
시사점: 메시지/기획/영업에 어떻게 적용할 수 있는가
```

**신뢰도 기준**

| 신뢰도 | 기준 |
|--------|------|
| 높음 | 3개 이상 독립 출처에서 등장, 자발적으로 언급됨 |
| 중간 | 2개 출처 또는 유도 질문에서만 등장 |
| 낮음 | 단일 출처, 아직 검증 필요 |

## 페르소나 작성

최소 5~10개 데이터 포인트 없이 페르소나 만들지 않는다. 데이터 기반이 아닌 가상의 페르소나는 오히려 방향을 잘못 잡게 한다.

**페르소나 구조**

```
## [페르소나 이름] — [직책/역할]

프로필
- 직책 범위: (예: "마케팅 팀장 ~ CMO")
- 회사 규모: (예: "직원 50~300명, B2B SaaS")
- 주요 KPI: [무엇으로 성과를 평가받는가]

핵심 과업
[한 문장: 이 사람이 달성하려는 결과]

트리거 이벤트
[솔루션을 찾기 시작하는 계기들]

주요 불만
1. [불만 — 가능하면 실제 표현 그대로]
2.
3.

원하는 결과
- [성공의 모습]
- [측정 방식]
- [주변에 어떻게 보이고 싶은가]

구매 망설임 / 반론
- [주요 걱정]

대안 탐색
- [경쟁사, DIY, 아무것도 안 함, 외주 고용 등]

자주 쓰는 표현
- "[직접 인용]"
- "[직접 인용]"
```

## 결과물 형식 선택

필요한 것을 말해주면 그에 맞게 작성한다:

1. **리서치 인사이트 요약** — 테마, 인용, 패턴 정리
2. **VOC 표현 모음** — 카피에 바로 쓸 수 있는 고객 언어 목록
3. **페르소나 문서** — 1~3개 페르소나
4. **JTBD 맵** — 고객 과업 구조화
5. **리서치 공백 분석** — 아직 모르는 것과 어떻게 알아볼지
