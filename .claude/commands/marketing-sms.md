SMS 및 모바일 메시지 마케팅 캠페인을 기획하고 작성합니다.

**시작 전 확인사항**:

1. **채널**: SMS? 카카오 알림톡? 카카오 친구톡? 앱 푸시?
2. **목적**: 프로모션? 트랜잭션? 리마인드? 재활성화?
3. **수신자**: 누가 받는가? (기존 고객, 비구매자, 특정 세그먼트)
4. **발송 타이밍**: 언제 보낼 것인가?

---

## SMS/모바일 메시지 핵심 원칙

**수신 동의 필수**
- 발송 전 반드시 마케팅 수신 동의 확인
- 미동의자 발송은 법적 문제 발생 가능

**짧고 직접적으로**
- 문자는 열람률 98% — 긴 설명 불필요
- 핵심 정보 + 링크로 충분

**적절한 빈도**
- 과도한 발송은 수신 거부율 급증
- 월 2~4회 이내 권장 (구독자 성향에 따라 다름)

---

## 채널별 특성

| 채널 | 특징 | 적합한 용도 |
|------|------|------------|
| SMS | 가장 높은 도달률 | 중요 알림, 단순 프로모션 |
| 카카오 알림톡 | 카카오 계정 필요, 템플릿 승인 | 거래 알림, 배송, 예약 |
| 카카오 친구톡 | 채널 친구만 수신 | 프로모션, 이벤트 |
| 앱 푸시 | 앱 설치 필요, 거부 쉬움 | 행동 기반 트리거 |

## 메시지 유형별 가이드

### 프로모션 메시지

```
[브랜드명] 한정 특가!
[혜택 내용] — [기한]
[링크 또는 코드]
수신거부 [080-XXXX]
```

**규칙**:
- 브랜드명 먼저 (누군지 알아야 읽음)
- 혜택 구체적으로
- 마감 기한 명시
- 수신 거부 번호 포함 (법적 의무)

### 리마인드 메시지

```
[이름]님, [행동]을 아직 완료하지 않으셨어요.
[남은 것] — [링크]
```

### 재활성화 메시지

```
[기간] 동안 뵙지 못했네요 🙂
[혜택] 드리고 싶어서 연락했어요.
[링크]  |  수신거부 [080-XXXX]
```

## 성과 지표

| 지표 | 벤치마크 |
|------|---------|
| 오픈률 | 95~98% (SMS), 50~60% (앱 푸시) |
| 클릭률 | 10~20% |
| 전환율 | 이메일 대비 3~5배 높음 |
| 수신거부율 | 1% 이하 유지 목표 |

---

## 주의사항

- 야간 발송 금지 (오후 9시~오전 8시)
- 광고 문자는 반드시 "[광고]" 표기
- 개인정보보호법 및 정보통신망법 준수
- 수신 거부자 즉시 DB에서 제외
