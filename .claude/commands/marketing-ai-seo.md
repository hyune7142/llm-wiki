ChatGPT, Perplexity, 구글 AI Overview 등 AI 검색 엔진에서 브랜드와 제품이 노출되도록 최적화합니다.

**배경**: 검색 패턴이 바뀌고 있다. 구글 대신 AI에게 직접 "뭐가 좋아?"라고 묻는 사람이 늘어나면서, AI가 추천하는 소스에 포함되는 것이 중요해졌다.

**시작 전 확인사항**:

1. **목표 AI 채널**: ChatGPT? Perplexity? 구글 AI Overview? 전체?
2. **타겟 키워드/질문**: 어떤 질문에서 등장하고 싶은가?
3. **현재 상황**: 지금 AI에서 어떻게 언급되는가?
4. **보유 콘텐츠**: 블로그, FAQ, 제품 페이지 등

## AI 검색 최적화 핵심 원리

AI는 여러 소스를 종합해 답변을 만든다. 우리가 그 소스에 포함되려면:

1. **신뢰할 수 있는 출처**로 인정받아야 한다
2. **명확하고 직접적인 답변**을 제공해야 한다
3. **자주 인용되는 콘텐츠**를 가져야 한다

---

## 핵심 최적화 전략

### 1. 명확한 답변 콘텐츠 작성

AI는 "이 질문에 대한 명확한 답"이 있는 페이지를 선호한다.

```
❌ "마케팅 자동화는 다양한 기능을 제공합니다..."
✅ "마케팅 자동화란 반복되는 마케팅 작업(이메일, SNS 등)을
    소프트웨어로 자동화하는 것입니다. 핵심 기능은..."
```

**콘텐츠 형식**:
- 질문-답변 형태 (FAQ)
- 정의 제공 (A는 B이다)
- 단계별 방법론
- 비교 표

### 2. 구조화된 데이터 (Schema Markup)

AI와 검색엔진이 콘텐츠를 쉽게 파악하게 한다. → `/marketing-schema` 스킬 참조

### 3. 권위 있는 백링크 확보

- 업계 미디어, 전문 블로그에서 인용
- 공동 연구/데이터 발표
- 전문가 인터뷰 참여

### 4. 멘션 및 인용 늘리기

- 업계 커뮤니티, 포럼, Reddit에서 언급
- 전문가들이 우리 데이터를 인용하게
- PR 활동으로 언론 인용 확보

## AI별 특성

| AI | 주요 소스 | 최적화 포인트 |
|----|-----------|-------------|
| ChatGPT | 학습 데이터 + 웹 검색 | 고품질 콘텐츠, Wikipedia급 명확성 |
| Perplexity | 실시간 웹 검색 | 최신 콘텐츠, 구조화된 답변 |
| 구글 AI Overview | 구글 인덱싱 | 기존 SEO + FAQ 구조 |
| 클로드 | 학습 데이터 | 고품질 명확한 콘텐츠 |
