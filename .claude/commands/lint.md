위키 전체를 점검하고 건강 상태를 보고합니다.

**진행 방식 (Claude에게)**:

사용자가 `/lint` 를 실행하면 아래 항목들을 순서대로 점검한다.

**점검 항목**:

1. **모순 탐지**: 페이지 간 서로 다른 주장이 있는지 확인한다.
2. **낡은 내용**: 더 최신 소스가 있는데 기존 페이지가 업데이트되지 않은 경우를 찾는다.
3. **고아 페이지**: 다른 페이지에서 링크가 걸리지 않은 페이지를 찾는다.
4. **누락된 페이지**: 여러 페이지에서 언급되지만 전용 페이지가 없는 개념/개체를 찾는다.
5. **누락된 크로스 레퍼런스**: 연결되어야 할 페이지가 서로 링크되지 않은 경우를 찾는다.
6. **데이터 공백**: 조사하면 위키가 더 풍부해질 주제나 질문을 제안한다.

**보고 형식**:

```
## 위키 점검 결과 — YYYY-MM-DD

### 발견된 문제
- 🔴 (즉시 수정 필요)
- 🟡 (여유 있을 때 수정)
- 🟢 (선택적 개선)

### 추천 액션
1. ...

### 다음에 조사해보면 좋을 것들
- ...
```

점검이 끝나면 "어떤 문제부터 수정할까요?" 라고 물어본다. 사용자가 선택하면 바로 수정 작업을 시작한다.

작업 완료 후 `wiki/log.md`에 항목 추가:
- 형식: `## [YYYY-MM-DD] lint | 발견 [N]건, 수정 [M]건`
