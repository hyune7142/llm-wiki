위키 내용을 기반으로 외부 공유·발표용 독립 문서를 생성하고 `exports/` 디렉토리에 저장합니다.

**진행 방식 (Claude에게)**:

사용자가 `/wiki-report`를 실행하거나, 위키 내용을 외부용 문서로 가공 요청하면:

1. **주제 확인**: 주제나 질문이 함께 입력되지 않았으면 "어떤 주제로 문서를 만들까요?" 라고 묻는다.
2. **형식 확인** (선택): 특별히 요청이 없으면 기본 마크다운 서술형으로 작성한다.
   - 기본: 마크다운 서술형
   - 비교 분석: 표 중심
   - 발표 자료: Marp 슬라이드 형식
   - 요약 브리핑: 핵심 포인트 목록

**작성 순서**:

1. **인덱스 확인**: `wiki/index.md`를 읽고 관련 페이지를 파악한다.
2. **페이지 읽기**: 관련 페이지들을 읽고 내용을 종합한다.
3. **문서 작성**: 아래 구조로 독립 문서를 작성한다.
   - 제목 및 작성일
   - 요약 (Executive Summary) — 3~5문장
   - 본문 — 주제에 맞게 구성
   - 참고 소스 — 근거가 된 위키 페이지 및 raw 파일 명시
   - `[[위키링크]]` 대신 일반 텍스트로 참조 (독립 문서이므로)
4. **파일 저장**: `exports/YYYY-MM-DD-[주제-슬러그].md`로 저장한다.
5. **운영 로그 정책**: `wiki/log.md`와 `wiki/hot.md`는 변경하지 않는다. 리포트는 외부 출력물이므로 위키 운영 이력에 누적하지 않는다.

**파일 형식**:

```markdown
---
title: 문서 제목
date: YYYY-MM-DD
topic: 주제 키워드
sources: []   # 참조한 wiki/ 또는 raw/ 파일 목록
---

# 문서 제목

> 작성일: YYYY-MM-DD

## 요약

(3~5문장 핵심 요약)

## 본문

(주제에 맞게 자유 구성)

## 참고 자료

(참조한 소스 목록 — 파일명 또는 제목)
```
