## 시작 전: 제품 마케팅 컨텍스트 확인

`.claude/product-marketing.md`가 있으면 먼저 읽고 시작한다. 이미 파악된 제품/고객/포지셔닝 정보는 다시 묻지 않는다. 파일이 없으면 `/marketing-product-marketing` 먼저 실행 권장.

---
경쟁사를 체계적으로 분석하고 구조화된 프로파일을 작성합니다.

**시작 전 확인사항**:

1. **분석할 경쟁사**: URL 또는 회사명
2. **우리 제품/서비스**: 간략한 설명 (포지셔닝 비교에 필요)
3. **분석 깊이**: 간단 스캔 vs 심층 분석
4. **우선 파악하고 싶은 영역**: 가격? 메시지? 기능? 고객층?

## 분석 원칙

**사실 기반, 추측 금지**
- 모든 주장은 출처(사이트, 후기, 기사) 명시
- 추정은 명확히 "추정"이라고 표시

**비교 가능하게**
- 모든 경쟁사에 같은 항목으로 분석 → 나란히 비교 가능

**현시점 스냅샷**
- 분석 날짜 명시, 특히 가격은 자주 바뀜

### 포지셔닝 & 메시지

- **핵심 가치 제안** (홈페이지 헤드라인 + 서브헤드라인)
- **타겟 고객** (카피/이미지에서 읽히는 타겟)
- **포지셔닝 각도** (예: 단순함 강조, 엔터프라이즈급, 올인원 등)
- **주요 메시지 테마** (반복 등장하는 키워드 3개)

### 제품/서비스

- 핵심 기능 목록
- 강조하는 차별점
- 연동/파트너십
- 최근 추가된 기능 (있으면)

### 가격 구조

| 플랜명 | 가격 | 주요 포함 사항 |
|--------|------|----------------|

- 무료 체험: 있음/없음, 기간
- 연간 할인: 있음/없음, 할인율

### 고객 & 소셜 프루프

- 대표 고객사
- 주요 업종
- 케이스스터디 핵심 성과 메시지
- 리뷰 평점 (가능하면)

### 콘텐츠 & 마케팅

- 블로그/콘텐츠 주제
- 주요 SNS 채널
- 특이한 마케팅 전략

## 간단 스캔 vs 심층 분석

**간단 스캔** (빠른 파악용)
- 홈페이지 + 가격 페이지만
- 포지셔닝, 가격, 핵심 기능만 정리

**심층 분석** (전략 수립용)
- 모든 주요 페이지 + 고객 후기 + 뉴스
- 경쟁사 3개 이하일 때 권장
