브랜드 노출과 SEO를 위한 디렉토리 및 플랫폼 등록 전략을 수립합니다.

**시작 전 확인사항**:

1. **제품/서비스 유형**: B2B SaaS? 에이전시? 로컬 비즈니스?
2. **목표**: 리드 확보? 백링크? 리뷰 수집?
3. **현재 등록 현황**: 이미 등록된 곳이 있는가?

## 등록 체크리스트

**기본 정보 준비**:
- [ ] 회사명 (일관성 중요 — 모든 플랫폼 동일)
- [ ] 웹사이트 URL
- [ ] 로고 (다양한 크기)
- [ ] 스크린샷 (최소 3~5장)
- [ ] 한 줄 설명 (100자 이내)
- [ ] 상세 설명 (500자, 1,000자 버전)
- [ ] 카테고리/태그
- [ ] 가격 정보

## G2 등록 및 리뷰 수집 전략

G2는 B2B 구매 의사결정에 가장 큰 영향을 미친다.

**초기 리뷰 수집**:
1. 현재 고객에게 리뷰 요청 이메일 발송
2. CS에서 긍정적 피드백 후 리뷰 유도
3. 분기별 리뷰 캠페인 진행

**리뷰 요청 이메일 예시**:
```
제목: [이름]님의 경험을 공유해주실 수 있을까요?

[이름]님,

[제품명] 사용 후기가 궁금합니다.
G2에 리뷰를 남겨주시면 다른 분들께도 큰 도움이 될 것 같아요.
5분이면 충분합니다 🙂

[리뷰 작성 링크]
```

## 디렉토리 SEO 효과

디렉토리 등록의 SEO 가치:
- **백링크**: 도메인 권위 있는 사이트에서 링크
- **브랜드 언급**: 브랜드 인지도 신호
- **리뷰 콘텐츠**: 검색 결과에 별점/리뷰 수 표시

- 모든 플랫폼 로그인 정보 한 곳에 정리

- 분기별 정보 업데이트 (가격, 기능 변경 시)
