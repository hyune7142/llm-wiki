신규 가입 전환율을 높이기 위한 가입 폼과 프로세스를 최적화합니다.

**시작 전 확인사항**:

1. **현재 가입 전환율**: 알면 공유
2. **가입 폼 현황**: 필드 수, 단계 수
3. **트래픽 출처**: 어디서 오는 방문자인가?
4. **가입 후 다음 단계**: 바로 서비스? 이메일 인증?

---

## 가입 최적화 핵심 원칙

**필드 = 마찰 = 이탈**
- 필드 하나가 줄 때마다 전환율 5~10% 상승
- "나중에 받을 수 있는 정보"는 나중에 받는다

**사회적 증거로 두려움 낮추기**
- 가입 폼 옆에 후기, 고객 수, 별점 배치
- "이미 X,000명이 사용 중"

**가입 버튼 문구가 중요하다**
```
❌ "제출하기", "가입하기", "확인"
✅ "무료로 시작하기", "14일 무료 체험 시작", "내 계정 만들기"
```

---

## 필수 vs 선택 필드

**가입 시 필수**:
- 이메일
- 비밀번호

**나중으로 미룰 것**:
- 전화번호 (온보딩 시 요청)
- 회사 규모/업종 (온보딩 시 요청)
- 신용카드 (유료 전환 시 요청)
- 프로필 사진 (프로필 설정 시)

---

## 소셜 가입 (Google, Kakao 등)

- 소셜 로그인은 전환율을 일반적으로 20~30% 높임
- 단, 이후 이메일 마케팅 허용 여부 별도 확인 필요
- 모바일에서 특히 효과적

---

## 단계별 가입 폼 (Multi-step)

단일 긴 폼보다 여러 짧은 단계가 효과적인 경우:

```
1단계: 이메일 + 비밀번호 (최소 정보)
       ↓ (이 정도만 있어도 계정 생성 가능)
2단계: 이름 + 역할
       ↓ (개인화에 필요한 정보)
3단계: 회사 규모 + 주요 목표
       ↓ (온보딩 커스터마이징용)
```

**진행 표시줄(Progress Bar)** 포함 시 완료율 향상

## 가입 페이지 요소 체크리스트

- [ ] 가입 이유가 명확한가? (무엇을 얻는가)
- [ ] 필드가 최소화되었는가?
- [ ] 소셜 가입 옵션이 있는가?
- [ ] 소셜 프루프가 보이는가?
- [ ] 버튼 문구가 가치를 전달하는가?
- [ ] 무료/유료 여부가 명확한가?
- [ ] 카드 정보 불필요함이 명시되어 있는가? (해당 시)
- [ ] 모바일에서 쉽게 입력 가능한가?
