## 시작 전: 제품 마케팅 컨텍스트 확인

`.claude/product-marketing.md`가 있으면 먼저 읽고 시작한다. 이미 파악된 제품/고객/포지셔닝 정보는 다시 묻지 않는다. 파일이 없으면 `/marketing-product-marketing` 먼저 실행 권장.

---
마케팅 성과를 올바르게 측정하고 인사이트를 도출합니다.

**시작 전 확인사항**:

1. **현재 추적 도구**: GA4, 네이버 애널리틱스, Mixpanel 등
2. **측정하고 싶은 것**: 어떤 전환이 가장 중요한가?
3. **현재 문제**: 어떤 데이터가 없는가? 뭐가 이상한가?
4. **기술 스택**: 어떤 플랫폼(WordPress, Shopify, 자체 개발 등)인가?

## 측정 핵심 원칙

**비즈니스 질문에서 역방향으로 시작한다**
1. 알고 싶은 것: "어떤 채널에서 가장 좋은 리드가 오는가?"
2. 필요한 데이터: 채널별 리드 수 + 전환율
3. 필요한 이벤트: 채널 파라미터 (UTM) + 폼 제출 추적

**추적할 것보다 안 추적할 것을 먼저 결정한다**
- 모든 클릭을 추적하면 중요한 게 묻힌다
- 비즈니스 결정에 영향 줄 지표만

## 핵심 이벤트 명명 규칙

일관성이 가장 중요하다.

**권장 형식**: `[객체]_[동작]`

```
signup_completed        — 가입 완료
lead_form_submitted     — 리드 폼 제출
demo_requested          — 데모 신청
purchase_completed      — 구매 완료
email_clicked           — 이메일 클릭
video_watched_50pct     — 영상 50% 시청
```

---

## UTM 파라미터 가이드

모든 외부 링크에 UTM을 붙여야 채널별 성과를 측정할 수 있다.

**UTM 구조**:
```
?utm_source=   [트래픽 출처] → google, newsletter, linkedin
&utm_medium=   [마케팅 채널] → cpc, email, social, organic
&utm_campaign= [캠페인 이름] → 2025q1-branding
&utm_content=  [광고 변형]   → banner-v1, cta-blue
&utm_term=     [키워드]      → (검색광고에서만)
```

**예시**:
```
https://example.com/landing?utm_source=linkedin&utm_medium=cpc&utm_campaign=hr-managers-q1
```

## 마케팅 퍼널별 핵심 지표

| 단계 | 지표 | 도구 |
|------|------|------|
| 인지 | 도달, 노출, 브랜드 검색량 | GA4, 광고 플랫폼 |
| 관심 | 방문자, 체류 시간, 이탈률 | GA4 |
| 고려 | 리드 수, 리드당 비용 (CPL) | CRM, 광고 |
| 전환 | 전환수, 전환율, 전환당 비용 (CPA) | GA4, CRM |
| 유지 | 재방문율, 구독 유지율, LTV | CRM, 이메일 도구 |

## 자주 틀리는 것

- **라스트 클릭만 보기**: 첫 터치 채널도 함께 봐야 함
- **샘플 크기 무시**: 방문자 100명 기준으로 전환율 결론 내리지 말 것
- **계절성 무시**: 전주 대비 말고 전년 동기 대비도 확인
- **가상 전환 추적**: "전화 버튼 클릭"을 전환으로 잡으면 실제 전환과 다름
