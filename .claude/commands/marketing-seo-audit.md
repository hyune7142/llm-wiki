웹사이트 SEO 현황을 점검하고 개선 방향을 제시합니다.

**시작 전 확인사항**:

1. **분석할 URL**: 도메인 또는 특정 페이지
2. **목표 키워드**: 어떤 검색어로 노출되고 싶은가?
3. **현재 상황**: 검색 순위, 트래픽 현황 (알면 공유)
4. **경쟁 환경**: 주요 경쟁사 도메인

## SEO 감사 5영역

### 1. 기술 SEO (Technical)

사이트가 검색엔진에 제대로 인덱싱되는가?

**체크 항목**:
- [ ] 사이트 로딩 속도 (3초 이하 목표)
- [ ] 모바일 최적화
- [ ] SSL (https) 적용
- [ ] sitemap.xml 존재
- [ ] robots.txt 설정
- [ ] 404 오류 페이지 관리
- [ ] 중복 콘텐츠 없음

### 2. 온페이지 SEO (On-Page)

각 페이지가 타겟 키워드에 최적화되어 있는가?

**체크 항목**:
- [ ] 제목 태그 (Title) — 타겟 키워드 포함, 60자 이내
- [ ] 메타 디스크립션 — 160자 이내, 클릭 유도 문구
- [ ] H1 태그 — 페이지당 1개, 핵심 키워드 포함
- [ ] URL 구조 — 짧고 키워드 포함
- [ ] 이미지 alt 텍스트
- [ ] 내부 링크 구조

### 3. 콘텐츠 품질

- 각 페이지가 명확한 타겟 키워드가 있는가?
- 경쟁 페이지보다 더 깊은 정보를 제공하는가?
- 사용자 의도에 맞는 콘텐츠인가?

### 4. 백링크 프로파일

- 외부 도메인에서 링크가 들어오는가?
- 링크 품질은 어떤가? (스팸 사이트 여부)
- 경쟁사 대비 링크 수는?

### 5. 사용자 신호

- 이탈률이 높지 않은가? (70% 이상이면 콘텐츠 문제)
- 체류 시간이 충분한가?
- 클릭률(CTR)이 낮지 않은가?

## 키워드 전략

**키워드 유형별 전략**:

| 키워드 유형 | 검색량 | 전환율 | 집중 전략 |
|------------|--------|--------|-----------|
| 브랜드 키워드 | 낮음 | 높음 | 브랜드 보호 |
| 정보성 키워드 | 높음 | 낮음 | 콘텐츠 SEO |
| 비교 키워드 | 중간 | 높음 | 비교 페이지 |
| 구매 키워드 | 낮음 | 매우 높음 | 랜딩페이지 최적화 |
