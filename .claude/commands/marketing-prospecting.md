## 시작 전: 제품 마케팅 컨텍스트 확인

`.claude/product-marketing.md`가 있으면 먼저 읽고 시작한다. 이미 파악된 제품/고객/포지셔닝 정보는 다시 묻지 않는다. 파일이 없으면 `/marketing-product-marketing` 먼저 실행 권장.

---
이상적인 고객 프로파일(ICP)에 맞는 잠재 고객 리스트를 만듭니다.

**시작 전 확인사항**:

1. **ICP 정의**: 업종, 회사 규모, 타겟 직책, 지역
2. **우리 제품/서비스**: 어떤 고객에게 가장 잘 맞는가?
3. **기존 최고 고객**: 이미 있는 고객 중 가장 좋은 고객은?
4. **접근 방법**: 이메일? 전화? 링크드인?

---

## 3가지 프로스펙팅 경로

### 경로 1: B2B 일반

- 업종 + 회사 규모 + 직책 조합
- 발굴 도구: 링크드인, 잠재고객 DB, 협회 목록

### 경로 2: 스타트업/SaaS

- 기술 스택, 최근 투자, 채용 신호 활용
- 성장 신호 있는 곳이 구매 가능성 높음

### 경로 3: 로컬 SMB

- 업종 + 지역 + 접근 가능성
- 네이버 지도, 업종별 협회, 주변 네트워크

---

## 5단계 프로스펙팅 프로세스

### 1단계: ICP 정의

```
업종:
회사 규모:
타겟 직책:
지역:
예산 수준 (추정):
사용 기술/도구 (있으면):
트리거 이벤트 (성장, 채용, 투자 등):
```

### 2단계: 후보 발굴

최소 2~3개 출처에서 교차 검증:

| 출처 | 방법 |
|------|------|
| 링크드인 | 고급 검색 (직책 + 업종 + 규모) |
| 업종별 협회 | 회원사 목록 |
| 이벤트 참가사 | 업계 행사 참가 기업 |
| 기존 고객 네트워크 | 추천 요청 |
| 뉴스/기사 | 최근 투자/성장 기업 |

### 3단계: 자격 검증

각 후보에 대해 확인:

- ICP 기준 충족하는가?
- 구매할 가능성이 있는 신호가 있는가?
- 연락 가능한 담당자가 있는가?

### 4단계: 우선순위 분류

| 등급 | 기준 |
|------|------|
| 🔥 최우선 | ICP 완벽 충족 + 구매 신호 |
| ⭐ 우선 | ICP 대부분 충족 |
| 보통 | ICP 일부 충족 |
| 제외 | ICP 미충족 |

### 5단계: 리스트 정리

```
| 회사명 | 담당자 | 직책 | 이메일 | 출처 | 우선순위 | 접근 예정일 |
|--------|--------|------|--------|------|----------|------------|
```
