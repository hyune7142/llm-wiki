`.claude/product-marketing.md`가 있으면 먼저 읽고 시작한다. 이미 파악된 제품/고객/포지셔닝 정보는 다시 묻지 않는다. 파일이 없으면 `/marketing-product-marketing` 먼저 실행 권장.

이메일 리스트와 리드를 확보하는 리드 마그넷을 기획하고 만듭니다.

**시작 전 확인사항**:

1. **목적**: 이메일 리스트 구축? 특정 구매 단계 고객 확보?
2. **타겟 고객**: 누가 다운로드해야 하는가?
3. **고객이 가진 즉각적인 문제**: 지금 당장 해결하고 싶은 것
4. **우리 제품과의 연결고리**: 리드 마그넷 → 다음 단계는?

---

## 리드 마그넷 핵심 원칙

**하나의 문제, 하나의 해결책**
- 광범위한 "마케팅 완전 가이드" 금지
- "SNS 광고 전환율 2배 높이는 체크리스트" 처럼 구체적으로

**즉시 소비 가능해야 한다**
- 5분 안에 완독 가능하거나
- 바로 적용 가능한 실용 자료

**높은 지각 가치, 낮은 제작 비용**
- 실용적인 템플릿이 두꺼운 전자책보다 낫다

---

## 리드 마그넷 유형별 선택

| 유형 | 제작 시간 | 적합한 상황 |
|------|-----------|------------|
| 체크리스트 | 1~2시간 | 반복 작업이 있는 고객 |
| 템플릿 | 2~4시간 | 직접 쓸 수 있는 것 원하는 고객 |
| 미니 가이드 | 4~8시간 | 특정 방법론을 배우고 싶은 고객 |
| 계산기/툴 | 1~2일 | 수치 계산이 필요한 고객 |
| 이메일 코스 | 1~2주 | 여러 단계를 배워야 하는 고객 |
| 웨비나 | 1~2주 | 라이브 인터랙션 원하는 고객 |
| 전자책 | 2~4주 | 깊은 주제 탐구 필요 |

## 구매 단계별 매칭

| 단계 | 적합한 리드 마그넷 |
|------|-------------------|
| 인지 | 교육적 체크리스트, 가이드 |
| 고려 | 비교 가이드, 케이스스터디, 평가 도구 |
| 결정 | 구현 템플릿, ROI 계산기, 데모 신청 유도 |

## 랜딩 페이지 전환율 기준

| 트래픽 유형 | 목표 전환율 |
|------------|------------|
| 따뜻한 트래픽 (기존 팔로워, 이메일) | 20~40% |
| 차가운 트래픽 (광고, 검색) | 5~15% |

**전환율 높이는 법**:
- 폼 필드 최소화 (이름 + 이메일만)
- 리드 마그넷 미리보기 이미지 제공
- 즉각적인 혜택 강조 ("즉시 다운로드")
- 소셜 프루프 추가 ("1,200명이 다운로드")

## 리드 마그넷 콘텐츠 구조 (미니 가이드 기준)

```
제목: [구체적 결과]를 달성하는 [N]가지 방법

1. 표지 — 이름, 로고, 핵심 약속
2. 소개 (1페이지) — "이 자료가 도움이 될 사람"
3. 핵심 내용 (3~7페이지) — 실행 가능한 방법론
4. 다음 단계 (1페이지) — 우리 서비스/제품으로 자연스럽게 연결
```

---

## 리드 마그넷 → 전환 흐름

```
광고/SNS/검색 → 랜딩 페이지 → 이메일 입력 → 즉시 전달
→ 웰컴 이메일 → 너처 시퀀스 → 제품 소개 → 전환
```
