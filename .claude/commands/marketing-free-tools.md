잠재 고객이 자발적으로 찾아오는 무료 도구/계산기/템플릿을 기획합니다.

**왜 무료 도구인가**: 검색 트래픽 + 리드 수집 + 브랜드 인지도를 동시에 달성. 제대로 만든 무료 도구 하나가 수년간 리드를 생성한다.

**시작 전 확인사항**:

1. **타겟 고객**: 누가 이 도구를 쓸 것인가?
2. **제품과의 연결고리**: 도구 사용 후 어떤 우리 제품/서비스로 자연스럽게 이어지는가?
3. **제작 리소스**: 개발자 있는가? 노코드 툴 사용?
4. **현재 고객 고민**: 반복적으로 계산하거나 확인해야 하는 것이 있는가?

## 무료 도구 유형

| 유형 | 예시 | 제작 난이도 |
|------|------|------------|
| 계산기 | ROI 계산기, 가격 비교기 | 낮음 |
| 생성기 | 카피 생성기, 제목 생성기 | 중간 |
| 체커/감사 | SEO 체커, 이메일 점수 | 높음 |
| 템플릿 | Notion 템플릿, 스프레드시트 | 낮음 |
| 가이드/리포트 | 자동 생성 리포트 | 중간~높음 |

## 좋은 무료 도구의 조건

**즉각적인 가치 제공**
- 도구 쓰는 순간 바로 유용한 결과

**우리 제품과 자연스럽게 연결**
- "더 정확한 분석을 위해 [우리 제품]을..."
- 강매 느낌이 아닌 자연스러운 업셀

**공유될 만한 결과**
- 결과를 SNS에 공유하거나 팀에 보낼 수 있는 형태

**이메일 수집 (선택적)**
- 결과를 이메일로 받기 옵션
- 강제 이메일 수집은 완료율을 낮춤

---

## 도구 기획 순서

### 1단계: 아이디어 발굴

고객이 반복적으로 하는 계산/확인 목록 작성:
- 매달 하는 계산
- 결정 전 비교하는 것
- 에러가 생기기 쉬운 작업

### 2단계: 우선순위 결정

| 기준 | 배점 |
|------|------|
| 검색 볼륨 (이 도구를 찾는 사람 수) | 40% |
| 제품 연결성 | 30% |
| 제작 가능성 | 20% |
| 바이럴 가능성 | 10% |

### 3단계: 제작 방법 선택

**낮은 비용**:
- Google Sheets → 웹사이트에 삽입
- Notion 템플릿 → 무료 배포
- Typeform → 설문형 평가 도구

**중간 비용**:
- Webflow + 커스텀 JS
- 노코드 도구 (Glide, Softr)

**높은 비용**:
- 전용 개발
