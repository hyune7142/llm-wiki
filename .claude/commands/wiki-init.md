**진행 방식 안내 (Claude에게)**:

`/wiki-init`이 실행되면 아래 5가지 질문을 하나씩 묻는다. 첫 질문부터 바로 시작한다.

사용자의 답변을 받으면 아래 순서로 진행하세요:

1. 답변을 자연스럽게 확인하고("네, '[답변]'으로 하겠습니다!") 다음 질문으로 넘어간다.
2. 다섯 질문이 모두 끝나면 수집한 정보를 요약해서 보여주고 확인을 요청한다.
3. 사용자가 확인하면 CLAUDE.md의 `## 위키 기본 정보` 섹션을 업데이트한다:
   - `[미설정]` → 사용자 답변으로 교체
4. `wiki/log.md` 파일 맨 끝에 다음 항목을 추가한다 (파일을 읽지 않고 Edit으로 바로 추가): `## [오늘날짜] init | [위키 이름] 위키 초기 설정 완료`
5. 설정 완료 메시지와 함께 다음 단계를 안내한다:
   - `raw/` 폴더에 첫 소스를 넣고 "이 파일 처리해줘"라고 말하면 ingest가 시작됩니다.
   - 언제든 `/wiki-init`을 다시 실행해서 설정을 수정할 수 있습니다.

**다섯 가지 질문 목록**:
1. 위키 이름 → `위키 이름` 필드
2. 어떤 분야 / 주제를 다루나요? → `도메인 / 주제` 필드
3. 이 위키를 왜 만드시나요? 어떤 상황에서 활용하실 건가요? → `목적` 필드
4. 주로 어떤 종류의 자료를 추가하실 예정인가요? (예: 웹 아티클, 논문, 책 챕터, 회의 메모, 유튜브 자막, 개인 일기 등) → `주요 소스 유형` 필드
5. 정보를 어떻게 정리하는 게 편하신가요? (예: 저자/출처별, 시간순, 주제별 클러스터, 찬반 논점 정리 등) → `강조 관점 / 정리 방식` 필드
