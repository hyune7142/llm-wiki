## 시작 전: 제품 마케팅 컨텍스트 확인

`.claude/product-marketing.md`가 있으면 먼저 읽고 시작한다. 이미 파악된 제품/고객/포지셔닝 정보는 다시 묻지 않는다. 파일이 없으면 `/marketing-product-marketing` 먼저 실행 권장.

---
B2B 영업 콜드이메일을 작성합니다. 목표는 답장을 받는 것입니다.

**시작 전 확인사항**:

아래 정보를 먼저 파악한다. 이미 제공된 정보는 다시 묻지 않는다.

1. **수신자 정보**: 직책, 회사, 업종
2. **원하는 결과**: 미팅 잡기? 답장 받기? 데모 신청?
3. **핵심 가치 제안**: 우리가 이 회사에 줄 수 있는 구체적 가치
4. **증거/근거**: 유사 고객 사례, 실적, 수치
5. **리서치 포인트**: 최근 채용, 투자, 뉴스 등 맞춤 연결고리

---

## 핵심 원칙

**영업 기계가 아닌 똑똑한 동료처럼 써라**
- 딱딱한 영업 문체 금지
- 수신자 입장에서 읽히는 자연스러운 문장

**짧을수록 좋다**
- 본문 3~5문장이 이상적
- 모든 문장이 이유 있어야 한다

**한 가지만 부탁한다**
- "미팅 잡기 + 자료 보내기 + 전화 통화" 동시 요청 금지
- 부담 없는 질문 하나: "이 방향이 맞다면 15분만 시간 내주실 수 있을까요?"

**개인화는 진짜여야 한다**
- "귀사의 성장을 지켜봐왔습니다" 같은 공허한 문장 금지
- 구체적인 관찰: "최근 [직책] 채용 공고 3개를 봤는데요"

## 대상별 톤 조정

| 대상 | 톤 |
|------|-----|
| C레벨 (대표, CTO, CMO) | 극도로 간결, 동급 수준, 절제된 표현 |
| 실무 중간 관리자 | 구체적 가치, 약간 더 상세하게 |
| 기술직 | 정확한 표현, 허풍 없이, 전문성 존중 |

## 이메일 구조

정해진 구조는 없다. 자연스럽게 흐르면 프레임 없이 써도 된다.

**자주 쓰이는 형태**:

```
관찰 → 문제 → 증거 → 요청
(X를 봤는데, 보통 Y 문제가 있더라. Z 고객한테 해결해줬다. 관심 있으신가?)
```

**기본 구성 요소**:
```
제목        — 2~4단어, 소문자, 내부 이메일처럼 (예: "영업팀 효율화 관련")
본문 1줄    — 맞춤 관찰 (수신자/회사에 대한 구체적인 사실)
연결        — 관찰이 왜 연락하는 이유로 이어지는지 (1문장)
가치 제안   — 우리가 뭘 해줄 수 있는지 (1문장, 결과 중심)
증거        — 유사 고객 사례나 수치 (1문장)
CTA         — 관심 여부 확인하는 쉬운 질문 (1문장)
```

## 팔로업 시퀀스

답장이 없을 때 다른 각도로 접근한다. 같은 내용 반복 금지.

| 이메일 | 시점 | 전략 |
|--------|------|------|
| 1차 | 발송일 | 본 메일 |
| 2차 | 3~4일 후 | 새로운 각도 (다른 가치 포인트) |
| 3차 | 1주 후 | 간단한 자료/인사이트 공유 |
| 4차 | 2주 후 | 마지막 연락 ("바쁘실 거 알지만...") |

---

## 피해야 할 표현

❌ "안녕하세요, 저는 [회사]의 [이름]입니다. 오늘 연락드리는 이유는..."  
❌ "이 메일이 잘 전달되길 바랍니다"  
❌ "귀사에 딱 맞는 솔루션을 준비했습니다"  
❌ "RE:" 같은 가짜 답장 표시  
❌ 기능 나열 ("우리 제품은 A, B, C, D, E 기능이 있고...")

---

## 제목 예시

- "마케팅팀 관련" (단순, 내부 이메일처럼)
- "[회사명] + [구체적 주제]"
- "빠른 질문 하나" (호기심 유발)
- "혹시 [고통 포인트] 겪고 계신가요?"
