SNS 콘텐츠를 제작하고 소셜미디어 채널을 운영합니다.

**시작 전 확인사항**:

1. **목표**: 브랜드 인지도? 팔로워 성장? 리드 확보? 커뮤니티?
2. **타겟 고객**: 누가 봐야 하는가?
3. **주요 채널**: 인스타그램, 링크드인, 유튜브, 틱톡, 블로그 등
4. **브랜드 보이스**: 공식적인 / 친근한 / 전문적인 / 유머러스한
5. **리소스**: 주 몇 개, 어떤 형태로 만들 수 있는가?

## 플랫폼별 특성

| 플랫폼 | 잘 맞는 것 | 권장 빈도 | 핵심 형태 |
|--------|-----------|-----------|-----------|
| 링크드인 | B2B, 전문 지식, 채용 | 주 3~5회 | 텍스트 포스트, 카드뉴스 |
| 인스타그램 | 비주얼, 라이프스타일 | 매일 + 스토리 | 릴스, 카드뉴스 |
| 유튜브 | 심층 교육, 브이로그 | 주 1~2회 | 롱폼, 쇼츠 |
| 틱톡 | 브랜드 인지, 젊은층 | 하루 1~4회 | 쇼트폼 영상 |
| 블로그/브런치 | SEO, 전문성 | 주 1~2회 | 롱폼 아티클 |

## 콘텐츠 기둥 (필러) 설정

3~5개 주제 기둥 설정 예시 (B2B SaaS 마케터 기준):
- 업계 인사이트 (30%)
- 실무 팁/가이드 (25%)
- 교육 콘텐츠 (25%)
- 뒷이야기/과정 (15%)
- 제품/서비스 (5%)

## 후킹 문구 공식

첫 줄이 전부다. 스크롤을 멈추는 첫 문장 패턴:

| 유형 | 예시 |
|------|------|
| 호기심 | "많은 마케터들이 모르는 것: ___" |
| 공감 | "___를 해본 적 있으신가요?" |
| 반직관 | "솔직히 말하면, ___ 은 틀렸습니다" |
| 숫자 | "3년간 콘텐츠를 해보니 이것만 남았습니다" |
| 스토리 | "지난달, 저는 ___ 했습니다" |

## 플랫폼별 글쓰기 팁

**링크드인**
- 첫 줄이 핵심 (더 보기 전에 보임)
- 줄바꿈 자주 활용 (가독성)
- 개인 경험 + 업무 인사이트 조합

**인스타그램**
- 이미지/영상이 먼저, 캡션은 보조
- 첫 줄에서 저장/공유 이유 제시
- 해시태그 5~10개 (과도한 사용 금지)

**숏폼 영상 (릴스/틱톡/쇼츠)**
- 3초 안에 훅 (시각 + 텍스트 오버레이)
- 자막 필수 (소리 없이도 이해 가능하게)
- 구조: 문제 → 해결 → 결과 (30~60초)

## 콘텐츠 캘린더 주간 템플릿

```
월: [교육/팁] 콘텐츠
수: [케이스스터디/사례] 공유
금: [뒷이야기/과정] 콘텐츠
(매일) 스토리: 반응 유도, 투표, Q&A
```

---

## 콘텐츠 재활용 시스템

하나를 만들면 여러 곳에 쓴다:
- 블로그 글 → 링크드인 요약 포스트
- 링크드인 글 → 인스타 카드뉴스
- 인터뷰/미팅 → 쇼트폼 영상 클립 3개
- 뉴스레터 → 각 섹션별 SNS 포스트

## 참여 전략

**일일 30분 루틴**:
- 댓글 답하기 (5분)
- 타겟 계정 포스트에 의미 있는 댓글 달기 (15분)
- 관련 콘텐츠 공유 + 내 의견 추가 (5분)
- DM 팔로업 (5분)

**좋은 댓글의 조건**:
- 단순 동의 금지 ("좋은 글이네요!")
- 새로운 시각 추가 또는 경험 공유
