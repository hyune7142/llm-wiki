앱스토어(구글 플레이, 애플 앱스토어)에서 앱 노출과 다운로드를 최적화합니다.

**시작 전 확인사항**:

1. **대상 스토어**: 구글 플레이? 애플 앱스토어? 둘 다?
2. **앱 카테고리**: 어떤 종류의 앱인가?
3. **현재 현황**: 다운로드 수, 별점, 주요 키워드 순위
4. **주요 경쟁 앱**: 어떤 앱들과 경쟁하는가?

---

## ASO 핵심 영역

### 1. 앱 이름 / 제목

- 타겟 키워드 포함 (가장 중요한 SEO 요소)
- 앱스토어: 30자 이내
- 구글 플레이: 50자 이내

```
✅ "[브랜드명] — [카테고리/주요 기능 키워드]"
예: "카카오뱅크 — 스마트폰 은행"
```

### 2. 부제 (애플 앱스토어)

- 30자 이내
- 앱 이름에 못 넣은 보조 키워드

### 3. 키워드 필드 (애플 앱스토어)

- 100자 제한
- 앱 이름/부제에 없는 키워드만
- 공백 없이 쉼표로 구분

### 4. 앱 설명

**구글 플레이 (검색에 영향)**:
- 첫 167자가 가장 중요 (더보기 전에 보임)
- 주요 키워드 자연스럽게 포함
- 총 4,000자 이내

**작성 구조**:
```
1. 핵심 가치 제안 (1~2문장)
2. 주요 기능 목록 (불릿 형태)
3. 대상 고객
4. 차별점
5. CTA
```

## 비주얼 최적화

### 아이콘

- 단순하고 인식 가능해야 함
- 작은 크기(29px)에서도 식별 가능
- 텍스트 최소화

### 스크린샷

- 가장 중요한 기능을 처음 2~3장에
- 텍스트 오버레이로 각 화면 설명
- 일관된 디자인 언어

### 프리뷰 영상 (Preview Video)

- 15~30초
- 첫 5초가 핵심 (음소거 상태에서도 이해 가능)
- 실제 앱 화면 중심

## 별점 및 리뷰 관리

- 사용자가 긍정적인 경험 직후에 리뷰 요청 팝업
- 부정적 리뷰에 전문적으로 답변
- 반복되는 불만은 제품 개선으로 해결
