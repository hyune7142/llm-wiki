영업팀이 거래를 성사시키는 데 필요한 자료를 만듭니다.

**영업 자료의 핵심 원칙**: 영업담당자가 3초 안에 정보를 찾을 수 있어야 한다. 굵은 헤더, 짧은 불릿, 시각적 위계 구조 필수.

**시작 전 확인사항**:

1. **어떤 자료가 필요한가?** (세일즈 덱, 원페이저, 배틀카드, 데모 스크립트 등)
2. **타겟 바이어**: 누가 볼 것인가? (경영진, 실무자, IT 담당 등)
3. **우리 제품/서비스**: 핵심 기능, 가치 제안, 고객 사례
4. **주요 경쟁사**: 비교 대상
5. **가장 자주 나오는 반론**: 어떤 objection이 많은가?

## 자료 유형별 가이드

### 세일즈 덱 (발표 자료)

**슬라이드 구성 (10~12장)**:

```
1. 표지
2. 문제 제시 — 고객이 지금 겪는 상황
3. 현재 방식의 한계 — 왜 기존 방법이 안 되는가
4. 우리의 해결책 — 핵심 메시지 1가지
5. 작동 방식 — 3단계 이내로
6. 주요 기능/서비스 — 혜택 중심 (기능 나열 금지)
7. 고객 사례 — 구체적인 수치 포함
8. 소셜 프루프 — 고객사 로고, 인용
9. 가격/패키지 — 명확하게
10. 다음 단계 — CTA
11. (선택) FAQ / 기술 사양
```

**타겟별 맞춤**:
- 경영진 → ROI, 전략적 가치, 위험 감소
- 실무자 → 사용 편의성, 기능, 연동
- 예산 담당자 → TCO, ROI, 계약 유연성

### 원페이저 (한 장 요약)

30초 안에 훑어볼 수 있어야 한다.

**구성**:
```
헤드라인 (큰 글씨)
서브 헤드라인

| 문제 | 해결책 |
|------|--------|
| [고객 불만 1] | [우리가 해결하는 방법] |

핵심 3가지 차별점
[이모지/아이콘] 차별점 1
[이모지/아이콘] 차별점 2
[이모지/아이콘] 차별점 3

증거 (수치 + 로고)

연락처 / CTA
```

### 배틀카드 (경쟁사 대응)

영업 미팅 중 빠르게 참조할 수 있게.

**각 경쟁사별 구성**:
```
[경쟁사명] vs 우리

## 우리가 강한 상황
- [상황 1] → [우리 강점]
- [상황 2] → [우리 강점]

## 경쟁사가 강한 상황
- [상황] → [우리의 대응 포인트]

## 주요 반론 및 답변
Q: "[경쟁사] 쓰는데 왜 바꿔야 하나요?"
A: [간결하고 구체적인 답변]

## 절대 하지 말 것
- 경쟁사 비방
- 검증 안 된 주장
```

---

### 반론 처리 가이드

**가장 흔한 반론별 대응**:

| 반론 유형 | 핵심 접근 |
|-----------|-----------|
| 가격 | ROI, 기회 비용, 비교 대상 재프레이밍 |
| 타이밍 | "지금 안 하면 드는 비용"을 계산 |
| 경쟁사 | 우리만 할 수 있는 것에 집중 |
| 권한 없음 | 의사결정자 접근 방법 함께 설계 |
| 현 방식 유지 | 현재 방식의 숨겨진 비용 파악 |

### 데모 스크립트

**구성 (30~60분)**:

```
1. 디스커버리 리캡 (5분)
   - "지난번에 말씀하신 [문제] 맞죠?"
   - 오늘 확인하고 싶은 것 정리

2. 핵심 시나리오 시연 (15~20분)
   - [고객 문제] → [우리가 어떻게 해결하는지 보여주기]
   - 3~4개 핵심 워크플로우만

3. 참여 포인트
   - "지금 보신 기능 중 가장 도움이 될 것 같은 건?"
   - "현재 방식이랑 비교하면 어떤가요?"

4. 가치 요약 + 다음 단계
   - 오늘 본 것과 고객 문제 연결
   - 명확한 다음 단계 합의
```
