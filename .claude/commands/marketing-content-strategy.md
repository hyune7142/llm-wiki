## 시작 전: 제품 마케팅 컨텍스트 확인

`.claude/product-marketing.md`가 있으면 먼저 읽고 시작한다. 이미 파악된 제품/고객/포지셔닝 정보는 다시 묻지 않는다. 파일이 없으면 `/marketing-product-marketing` 먼저 실행 권장.

---
트래픽을 만들고 리드를 만드는 콘텐츠 전략을 수립합니다.

**시작 전 확인사항**:

1. **비즈니스 목표**: 인지도? 리드 확보? 검색 트래픽?
2. **타겟 고객**: 누구를 위한 콘텐츠인가?
3. **현재 콘텐츠 현황**: 기존에 뭐가 있는가? 어떤 게 잘 됐는가?
4. **경쟁 환경**: 이 분야에서 콘텐츠 잘 하는 곳은?
5. **리소스**: 얼마나 자주, 어떤 형태로 만들 수 있는가?

---

## 콘텐츠 전략 핵심 원칙

**검색 가능하거나, 공유 가능하거나, 둘 다이거나**
- 검색형: 이미 검색되는 수요를 잡는다 (SEO 중심)
- 공유형: 새로운 인사이트나 데이터로 확산을 노린다
- 검색이 기반이 되는 것이 장기적으로 더 안정적

**제품이 아닌 고객의 문제를 중심으로**
- "우리 제품 소개" 글은 잘 읽히지 않는다
- 고객이 검색하는 질문, 고민, 비교가 콘텐츠의 출발점

---

## 콘텐츠 기둥(필러) 설정

3~5개의 핵심 주제 기둥을 먼저 정한다.

**접근법 선택**:

| 접근법 | 방법 |
|--------|------|
| 제품 중심 | 제품이 해결하는 문제 → 관련 주제 |
| 고객 중심 | 타겟 고객의 일상 고민 → 토픽 클러스터 |
| 검색 중심 | 키워드 볼륨 분석 → 높은 수요 주제 |
| 경쟁사 중심 | 경쟁사 콘텐츠 분석 → 빈 틈 공략 |

---

## 구매 단계별 콘텐츠

| 단계 | 목적 | 토픽 유형 | 키워드 패턴 |
|------|------|-----------|------------|
| 인지 | 문제 인식 | 교육, 트렌드 | "[문제]란 무엇인가", "왜 [현상]이 일어나는가" |
| 고려 | 해결책 탐색 | 비교, 가이드 | "[방법] 비교", "최고의 [솔루션]" |
| 결정 | 구매 검토 | 케이스스터디, 리뷰 | "[제품명] vs [경쟁사]", "[제품명] 후기" |
| 활용 | 성공 지원 | 튜토리얼, 팁 | "[제품] 사용 방법", "어떻게 [목표] 달성하는가" |

## 콘텐츠 우선순위 프레임워크

아이디어가 많을 때 아래 기준으로 점수 매기고 우선순위 결정:

| 기준 | 가중치 | 체크 포인트 |
|------|--------|------------|
| 고객 임팩트 | 40% | 타겟 고객에게 얼마나 유용한가? |
| 콘텐츠-시장 적합도 | 30% | 이 형태가 우리에게 맞는가? |
| 검색 잠재력 | 20% | 검색량 있는가? 경쟁 강도는? |
| 제작 리소스 | 10% | 만들 수 있는가? 얼마나 걸리는가? |

## 콘텐츠 유형별 용도

| 유형 | 목적 |
|------|------|
| 가이드/방법론 글 | 검색 트래픽, 신뢰 구축 |
| 비교 글 | 구매 고려 단계 고객 포착 |
| 데이터/리서치 | 공유 확산, 링크 획득 |
| 케이스스터디 | 구매 설득, 사회적 증거 |
| 용어 사전/정의 | 롱테일 검색 트래픽 |
| 실용 템플릿 | 리드 마그넷, 실용 가치 |
| 전문가 인터뷰 | 신뢰도, 네트워크 확장 |

## 콘텐츠 리퍼포징 (재활용)

하나의 콘텐츠에서 여러 형태로 확장:
