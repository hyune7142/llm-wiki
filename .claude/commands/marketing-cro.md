`.claude/product-marketing.md`가 있으면 먼저 읽고 시작한다. 이미 파악된 제품/고객/포지셔닝 정보는 다시 묻지 않는다. 파일이 없으면 `/marketing-product-marketing` 먼저 실행 권장.

---
마케팅 페이지의 전환율을 분석하고 개선합니다.

**시작 전 확인사항**:

1. **분석할 페이지**: URL 또는 설명
2. **현재 전환율**: 알고 있으면 공유
3. **목표 전환**: 어떤 행동을 원하는가? (가입, 구매, 문의 등)
4. **현재 문제 추정**: 어디서 막히는 것 같은가?

---

## CRO 7가지 분석 영역

### 1. 가치 제안 명확성 (임팩트: 최상)

- 3초 안에 무슨 제품인지 알 수 있는가?
- 타겟 고객의 언어를 쓰고 있는가?
- "왜 우리인가"가 명확한가?

**체크**:
- 헤드라인만 읽어도 이해되는가?
- 경쟁사와 구별되는 표현인가?

### 2. 헤드라인 효과

좋은 헤드라인 패턴:
- `[대상]을 위한 [결과]`
- `[기간] 안에 [결과] 달성`
- `[경쟁 방식] 없이 [원하는 것]`

### 3. CTA (행동 유도)

- 버튼 문구가 동작 동사인가?
- 가장 중요한 CTA가 위에 있는가?
- 2개 이상의 CTA가 경쟁하지 않는가?

❌ "제출하기", "확인", "더 보기"  
✅ "무료로 시작하기", "30일 체험 시작", "견적 받기"

### 4. 시각적 위계 구조

- 스캔만 해도 핵심을 파악할 수 있는가?
- 눈이 자연스럽게 CTA로 향하는가?
- 모바일에서도 잘 보이는가?

### 5. 신뢰 신호 (Trust Signals)

- 고객사 로고 있는가?
- 후기/인용구가 실명+직책 포함인가?
- 수상/언론 노출 있는가?
- 보안/인증 배지가 있는가?

### 6. 반론 처리

- 주요 구매 망설임이 해소되는가?
- FAQ가 실제 질문을 다루는가?
- 보증/환불 정책이 명확한가?

### 7. 마찰 제거

- 폼 필드가 최소화되었는가?
- 페이지 로딩이 빠른가? (3초 이내)
- 팝업이 너무 일찍 뜨지 않는가?

## 결과물 형식

분석 후 아래 구조로 제안:

```
## [페이지명] CRO 분석 — [날짜]

### 즉시 수정 (Quick Wins)
- [문제]: [제안]

### 높은 임팩트 변경 (우선 실행)
- [문제]: [제안]

### A/B 테스트 아이디어
- 가설: [현재] 대신 [변형]으로 바꾸면 [지표]가 개선될 것이다
```

## 전환율 벤치마크

| 페이지 유형 | 양호한 전환율 |
|------------|-------------|
| 홈페이지 → 가입 | 2~5% |
| 랜딩페이지 (따뜻한 트래픽) | 10~25% |
| 랜딩페이지 (차가운 트래픽) | 2~5% |
| 리드 마그넷 | 20~40% |
