## 시작 전: 제품 마케팅 컨텍스트 확인

`.claude/product-marketing.md`가 있으면 먼저 읽고 시작한다. 이미 파악된 제품/고객/포지셔닝 정보는 다시 묻지 않는다. 파일이 없으면 `/marketing-product-marketing` 먼저 실행 권장.

비즈니스 상황에 맞는 종합 마케팅 전략을 수립합니다.

**중요**: 일반적인 마케팅 플랜이 아닌, 현재 예산·팀·단계에 맞춘 실행 가능한 계획만 작성합니다.

**시작 전 확인사항**:

1. **현재 비즈니스 상황**: 단계 (초기/성장/스케일), 매출, 팀 규모
2. **마케팅 예산**: 월/분기 가용 예산
3. **타겟 고객**: ICP, 현재 주요 고객
4. **현재 하고 있는 마케팅**: 어떤 채널, 어떤 성과
5. **목표**: 6~12개월 안에 무엇을 달성해야 하는가?
6. **주요 과제**: 지금 가장 막히는 부분은?

## AARRR 프레임워크로 분석

마케팅 플랜은 고객 여정 전체를 커버한다.

| 단계 | 의미 | 핵심 질문 |
|------|------|-----------|
| **Acquisition** | 신규 유입 | 어떻게 처음 만나는가? |
| **Activation** | 첫 가치 경험 | 첫 경험이 좋은가? |
| **Retention** | 반복 사용 | 계속 돌아오는가? |
| **Referral** | 추천 | 주변에 알리는가? |
| **Revenue** | 수익화 | 얼마나 벌고 있는가? |

---

## 플랜 구성 섹션

### 1. 현황 진단

- 잘 되는 것 / 안 되는 것
- 병목 지점 (어느 단계에서 고객이 이탈하는가)
- 활용 중인 채널과 각 채널 성과

### 2. 전략 방향

- **포지셔닝**: 누구를 위해 무엇을 (경쟁사 대비)
- **ICP**: 이상적인 고객 프로파일
- **브랜드 보이스**: 어떤 톤으로 소통할 것인가

### 3. 채널별 전술

**단계별 채널 추천**:

| 단계 | 무료/저비용 | 유료 |
|------|------------|------|
| 초기 | 콘텐츠, 커뮤니티, 콜드아웃바운드 | 소규모 타겟 광고 |
| 성장 | SEO, 파트너십, 이메일 | 성과 기반 광고 확장 |
| 스케일 | 브랜드, 추천 프로그램 | 대규모 캠페인 |

### 4. 90일 로드맵


## 단계별 핵심 집중 포인트

**초기 (PMF 탐색 중)**
- 아웃바운드 중심 (콜드이메일, 직접 접촉)
- 10명의 고객을 깊게 이해하는 것이 먼저

**성장 (PMF 확인 후)**
- 콘텐츠 + SEO로 인바운드 기반 구축
- 광고 채널 1~2개 집중 테스트

**스케일**
- 검증된 채널에 예산 집중
- 추천/파트너십으로 CAC 낮추기
