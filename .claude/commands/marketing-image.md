마케팅 이미지 콘셉트를 기획하고 제작 디렉션을 제공합니다.

**참고**: 이 스킬은 이미지를 직접 생성하지 않습니다. 콘셉트 기획, 카피, 구성 요소 디렉션을 제공합니다. 실제 이미지 생성은 AI 이미지 도구(Midjourney, DALL-E, Canva AI 등)나 디자이너와 함께 진행하세요.

**시작 전 확인사항**:

1. **이미지 용도**: SNS 포스팅? 광고 배너? 블로그 썸네일? 카드뉴스?
2. **플랫폼**: 인스타그램, 링크드인, 유튜브, 웹사이트 등
3. **전달하려는 메시지**: 이미지로 무엇을 말하고 싶은가?
4. **브랜드 스타일**: 색상, 톤 가이드가 있으면 공유

## 마케팅 이미지 유형별 가이드

### SNS 카드뉴스 (정보형)

**구성**:
```
1장: 훅 카드 — 제목 + 관심 유발 이미지
2~N장: 내용 카드 — 핵심 포인트 1개씩
마지막: CTA 카드 — 행동 유도 + 계정 태그
```

**디자인 원칙**:
- 텍스트 최소화 (한 카드에 30자 이내)
- 일관된 색상 팔레트 (2~3가지)
- 여백 충분히

### 광고 배너

**필수 요소**:
- 헤드라인 (핵심 혜택)
- 서브텍스트 (간단한 보완)
- CTA 버튼
- 로고

**금지**:
- 텍스트 20% 이상 (특히 메타 광고)
- 너무 많은 정보

### 유튜브 썸네일

**성과 높은 공식**:
- 얼굴 + 감정 표현 (클릭률 ↑)
- 대비가 강한 텍스트 (3~5단어)
- 핵심 키워드 + 숫자
- 밝은 배경 또는 강한 대비

## AI 이미지 생성 프롬프트 작성법

Midjourney, DALL-E, Stable Diffusion 등에서 사용:

**기본 구조**:
```
[피사체/장면], [스타일/분위기], [색상], [구도], [품질 키워드]
```

**B2B 마케팅 이미지 예시**:
```
Professional team collaboration in modern office, 
clean minimal style, blue and white color palette,
birds eye view, high quality, business photography
```

**피해야 할 것**:
- 저작권 있는 인물/브랜드 언급
- 실제 얼굴 생성 (초상권)
