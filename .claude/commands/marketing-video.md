## 시작 전: 제품 마케팅 컨텍스트 확인

`.claude/product-marketing.md`가 있으면 먼저 읽고 시작한다. 이미 파악된 제품/고객/포지셔닝 정보는 다시 묻지 않는다. 파일이 없으면 `/marketing-product-marketing` 먼저 실행 권장.

---
마케팅 영상을 기획하고 스크립트를 작성합니다.

**시작 전 확인사항**:

1. **영상 유형**: 숏폼(60초 이하)? 롱폼? 제품 데모? 설명 영상?
2. **플랫폼**: 유튜브, 인스타그램 릴스, 틱톡, 유튜브 쇼츠
3. **목표**: 인지도? 리드? 전환?
4. **타겟 고객**: 누가 볼 것인가?
5. **제작 리소스**: 카메라 촬영? AI 도구? 화면 녹화?

## 영상 유형별 가이드

### 숏폼 (15~60초) — 릴스/틱톡/쇼츠

**3초 법칙**: 첫 3초 안에 멈추게 해야 한다.

```
0~3초:   훅 (시각 + 텍스트 오버레이 + 말)
3~10초:  문제 또는 흥미 제시
10~45초: 핵심 내용
마지막:  CTA 또는 여운
```

**숏폼 스크립트 구조**:

| 구조 | 시간 | 예시 |
|------|------|------|
| 문제-해결 | 30초 | "이 문제 있으면 보세요 → 이렇게 하면 됩니다" |
| 리스트형 | 45초 | "마케터가 모르는 3가지 → 1, 2, 3" |
| 튜토리얼 | 60초 | "따라하면 됩니다 → 단계별 시연" |
| 스토리 | 60초 | "솔직히 말하면... → 배운 것 → 결론" |

---

### 제품 데모 영상 (2~5분)

```
1. 훅 (10초): 어떤 문제를 해결하는지
2. 상황 설정 (30초): "이런 상황 있으셨나요?"
3. 데모 (주요 부분): 핵심 기능 3가지만
4. 결과 보여주기: 전과 후
5. CTA: 다음 단계
```

---

### 유튜브 롱폼 (5~15분)

```
0:00~0:30  훅 — 왜 이 영상을 끝까지 봐야 하는가
0:30~1:00  약속 — 이 영상에서 얻을 것
1:00~끝부분 본론
끝부분     요약 + CTA + 다음 영상 유도
```

## 자막 및 텍스트 오버레이

**필수**: 소리 없이도 이해 가능하게

- 핵심 문장은 화면에 텍스트로 표시
- 자막: 자동 생성 후 수정
- 핵심 포인트는 강조 텍스트

---

## AI 영상 도구 활용 (참고)

| 도구 | 용도 |
|------|------|
| HeyGen, Synthesia | AI 아바타 영상 (촬영 없이) |
| CapCut, Descript | 편집 + 자막 자동 생성 |
| Opus Clip | 롱폼 → 숏폼 클립 자동 추출 |

## 영상 성과 지표

| 지표 | 의미 |
|------|------|
| 시청 유지율 (Retention) | 어디서 사람들이 끄는가 |
| 클릭률 (CTR) | 썸네일과 제목의 힘 |
| 댓글/공유 | 감성적 반응 |
| 전환 | 영상 → 행동 |
