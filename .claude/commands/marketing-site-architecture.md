SEO와 전환에 최적화된 웹사이트 구조를 설계합니다.

**시작 전 확인사항**:

1. **웹사이트 목적**: B2B SaaS? 커머스? 서비스업? 콘텐츠?
2. **타겟 방문자**: 어떤 사람들이 오는가?
3. **주요 전환 목표**: 가입? 문의? 구매?
4. **현재 사이트**: 있으면 URL 공유, 없으면 새로 설계

---

## 사이트 구조 설계 원칙

**방문자 여정 기반**
- 처음 온 사람이 다음에 어디로 가야 하는지 명확하게
- 모든 페이지에서 다음 행동이 보여야 한다

**SEO 크롤링 최적화**
- 3 클릭 이내로 어떤 페이지도 도달 가능
- 관련 페이지 간 내부 링크 촘촘하게

---

## 일반적인 B2B SaaS 사이트 구조

```
홈
├── 제품/서비스
│   ├── 기능 개요
│   ├── 기능별 상세 페이지
│   └── 로드맵
├── 솔루션 (세그먼트별)
│   ├── [업종]별 솔루션
│   └── [역할]별 솔루션
├── 가격
├── 고객 사례
│   └── 케이스스터디 목록
├── 리소스
│   ├── 블로그
│   ├── 가이드/전자책
│   └── 웨비나
└── 회사
    ├── 소개
    ├── 채용
    └── 문의
```

## URL 구조 설계

**원칙**:
- 짧고 키워드 포함
- 계층 구조 반영
- 한국어 URL은 인코딩 문제로 영문 권장

**예시**:
```
https://example.com/features/           → 기능 개요
https://example.com/features/reporting/ → 보고서 기능
https://example.com/solutions/startup/  → 스타트업 솔루션
https://example.com/blog/               → 블로그 목록
https://example.com/blog/category/      → 카테고리
```

## 메뉴 구조 가이드

**상단 네비게이션 (최대 5~6개 항목)**:
- 제품/기능
- 솔루션 (세그먼트별)
- 가격
- 리소스
- 로그인
- CTA 버튼 (가입/데모)

**푸터 구조**:
- 제품 링크
- 회사 정보
- 법적 정보 (개인정보처리방침, 이용약관)
- 소셜 링크

---

## 전환 최적화 구조

**모든 중요 페이지에 CTA 배치**:
- 상단: 네비게이션 오른쪽
- 헤로: 헤드라인 아래
- 중간: 섹션 경계마다
- 하단: 페이지 끝

**관련 페이지 내부 링크**:
- 블로그 → 관련 기능 페이지
- 기능 페이지 → 케이스스터디
- 케이스스터디 → 가격 페이지

## 사이트맵 생성

```
/sitemap.xml 형식 예시:

<url>
  <loc>https://example.com/</loc>
  <changefreq>weekly</changefreq>
  <priority>1.0</priority>
</url>
```

**우선순위 설정**:
- 홈, 가격, 주요 기능 페이지: 1.0
- 솔루션 페이지: 0.8
- 블로그 포스트: 0.6
- 기타: 0.4
