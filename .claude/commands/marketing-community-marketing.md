**시작 전 확인사항**:

1. **목표**: 제품 피드백? 고객 유지? 입소문? 콘텐츠 확보?
2. **타겟 멤버**: 누가 참여해야 하는가?
3. **제공할 가치**: 커뮤니티에 들어오면 뭘 얻는가?
4. **운영 리소스**: 누가 얼마나 시간을 쓸 수 있는가?
5. **플랫폼**: 이미 있는 채널이 있는가?

## 커뮤니티 성공 핵심 원칙

**제품이 아닌 구성원 중심으로 설계**
- "우리 제품 사용자 모임"이 아닌 "[업종/역할]을 위한 커뮤니티"
- 예: "마케터 커뮤니티" > "[제품명] 사용자 그룹"

**커뮤니티 플라이휠**
```
멤버 입장 → 가치 획득 → 참여 → 새 멤버 유입 → 반복
```

**가치가 먼저, 판매는 나중**
- 커뮤니티 안에서 적극적인 영업 금지
- 자연스럽게 제품을 언급하는 맥락 만들기

## 론칭 전 단계 (0 → 커뮤니티)

### 1단계: 창립 멤버 모집 (20~50명)

- 개인적으로 연락하는 방식으로 초대
- "우리 커뮤니티에 참여하세요"가 아닌 "함께 만들어가고 싶은 사람을 찾고 있어요"
- 활발하게 참여할 것 같은 사람 위주로

### 2단계: 문화 먼저 만들기

- 행동 강령(어떤 건 되고 안 되는지) 공개 론칭 전 수립
- 초기 대화 시드: 직접 흥미로운 질문을 먼저 올린다

### 3단계: 공개 론칭

- 창립 멤버에게 먼저 홍보 권한 부여
- 첫 달은 운영자가 모든 포스트에 응답

## 커뮤니티 건강도 지표

| 지표 | 목표 |
|------|------|
| 일/월 활성 사용자 비율 | 20% 이상 |
| 신규 가입 후 첫 주 내 포스트 | 30% 이상 |
| 스레드 응답률 | 80% 이상 (운영 초기) |
| 스태프 외 콘텐츠 비율 | 50% 이상 (성숙 단계) |

## 주간 운영 루틴

```
월: 주간 토픽 오픈 (질문, 투표, 사례 공유)
수: 멤버 스포트라이트 또는 인사이트 공유
금: 주간 요약 + 감사 인사
매일: 모든 댓글 24시간 내 응답
```
