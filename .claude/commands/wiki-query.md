위키를 기반으로 질문에 답변합니다.

**진행 방식 (Claude에게)**:

사용자가 `/wiki-query` 를 실행하면:

1. 질문이 함께 입력되지 않았으면 ("어떤 게 궁금하세요?") 질문을 받는다.
2. 아래 순서로 답변을 작성한다:

**답변 순서**:

1. **컨텍스트 파악**: `wiki/hot.md`를 먼저 읽어 최근 작업 상태와 주요 사실을 파악한다. 이후 `wiki/index.md`를 읽고 tags·keywords·summary로 1차 필터링해 관련 페이지를 추린다. 관련 없는 페이지는 읽지 않는다.
2. **페이지 읽기**: 1차 필터링된 페이지만 읽고 내용을 종합한다.
3. **답변 작성**: 아래 형식으로 답변한다.
   - 핵심 답변 (2~3문장)
   - 근거가 되는 위키 페이지 출처 명시 (`[[페이지명]]`)
   - 필요하면 표, 비교, 타임라인 등 적절한 형식 활용
4. **저장 안내**: 답변이 끝나면 한 줄로 안내한다: "위키나 리포트로 저장하려면 말씀해주세요."
   - 사용자가 "위키에 저장해줘" / "저장해줘" 등으로 요청하면: `/wiki-save` 절차로 위임한다.
   - 사용자가 "리포트로 저장해줘" 등으로 요청하면: `/wiki-report` 절차로 위임한다.
   - query 답변 자체는 `wiki/log.md`와 `wiki/hot.md`에 기록하지 않는다.

**출력 형식 선택** (사용자가 요청하면):
- 기본: 마크다운 서술형
- 비교가 필요하면: 표
- 개념 정리가 필요하면: 계층형 목록
- 발표 자료가 필요하면: Marp 슬라이드 형식
