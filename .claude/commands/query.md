---

위키를 기반으로 질문에 답변합니다.

**진행 방식 (Claude에게)**:

사용자가 `/query` 를 실행하면:

1. 질문이 함께 입력되지 않았으면 ("어떤 게 궁금하세요?") 질문을 받는다.
2. 아래 순서로 답변을 작성한다:

**답변 순서**:

1. **인덱스 확인**: `wiki/index.md`를 읽고 질문과 관련된 페이지를 파악한다.
2. **페이지 읽기**: 관련 페이지들을 읽고 내용을 종합한다.
3. **답변 작성**: 아래 형식으로 답변한다.
   - 핵심 답변 (2~3문장)
   - 근거가 되는 위키 페이지 출처 명시 (`[[페이지명]]`)
   - 필요하면 표, 비교, 타임라인 등 적절한 형식 활용
4. **저장 여부 확인**: 답변이 끝나면 "이 답변을 위키에 저장해둘까요?" 라고 물어본다.
   - 사용자가 원하면 `wiki/query-[주제-슬러그].md`로 저장하고 index, log를 업데이트한다.
   - 형식: `## [YYYY-MM-DD] query | [질문 요약]`

**출력 형식 선택** (사용자가 요청하면):
- 기본: 마크다운 서술형
- 비교가 필요하면: 표
- 개념 정리가 필요하면: 계층형 목록
- 발표 자료가 필요하면: Marp 슬라이드 형식
