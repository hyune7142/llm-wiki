## 시작 전: 제품 마케팅 컨텍스트 확인

`.claude/product-marketing.md`가 있으면 먼저 읽고 시작한다. 이미 파악된 제품/고객/포지셔닝 정보는 다시 묻지 않는다. 파일이 없으면 `/marketing-product-marketing` 먼저 실행 권장.

---
고객 이탈을 줄이고 재활성화하는 전략을 수립합니다.

**시작 전 확인사항**:

1. **이탈 유형**: 자발적 이탈(취소)? 결제 실패(비자발적 이탈)?
2. **현재 이탈률**: 월간 이탈률
3. **주요 이탈 원인**: 알고 있으면 공유 (설문, CS 기록 등)
4. **서비스 유형**: 구독? 반복 구매? 서비스 계약?

---

## 이탈 유형 구분

### 자발적 이탈 (취소 플로우)

고객이 직접 취소를 선택하는 경우.

**취소 플로우 구조**:

```
취소 버튼 클릭
→ 이유 묻기 (취소 설문)
→ 맞춤 리텐션 오퍼
→ 확인 또는 수락
→ 취소 후 이메일
```

**이유별 맞춤 오퍼**:

| 취소 이유 | 제안 |
|-----------|------|
| 가격이 비쌈 | 할인 또는 다운그레이드 플랜 |
| 잘 안 씀 | 일시 정지(Pause) 옵션 |
| 기능 부족 | 로드맵 공유, 사용법 도움 |
| 다른 서비스로 이동 | 직접 비교, 전환 지원 |
| 일 끝남 | 재가입 프로모션 예약 |

---

### 비자발적 이탈 (결제 실패)

카드 만료, 잔액 부족 등으로 결제가 되지 않는 경우.

**결제 실패 대응 시퀀스**:

| 시점 | 액션 |
|------|------|
| 결제 실패 즉시 | 알림 이메일 발송 (부드럽게) |
| 3일 후 | 재시도 + 알림 이메일 |
| 5일 후 | 카드 업데이트 링크 + 긴급성 추가 |
| 7일 후 | 마지막 경고 + CS 안내 |
| 10일 후 | 계정 정지 알림 |

**목표 복구율**: 50~60%

## 이탈 신호 모니터링

이탈하기 전에 징조가 있다.

| 신호 | 의미 |
|------|------|
| 로그인 빈도 감소 | 사용 이탈 위험 |
| 핵심 기능 미사용 | 가치 미발견 |
| CS 문의 증가 | 불만족 가능성 |
| 결제 문의 | 가격 민감 |
| 이메일 오픈율 감소 | 관심 저하 |

**고위험군 대응**: 이탈 신호 감지 시 CS 또는 CS 이메일로 선제 연락

---

## 재활성화 캠페인

이미 떠난 고객을 다시 데려오는 전략.

**시퀀스 (3~4개 이메일)**:

| 이메일 | 각도 |
|--------|------|
| 1 | "오랜만입니다" + 최근 놓친 업데이트 |
| 2 | 개선된 점 강조 + 과거 문제 해결됨 |
| 3 | 특별 복귀 혜택 (기간 한정) |
| 4 | 마지막 연락 + 수신 관련 안내 |

**복귀 혜택 아이디어**:
- 첫 달 무료 또는 할인
- 업그레이드 플랜 체험
- 전용 온보딩 지원

---

## 이탈률 계산

```
월간 이탈률 = (이번 달 취소 수 ÷ 월초 총 고객 수) × 100

예: 100명 중 5명 취소 → 5% 월간 이탈률
```

**업종별 양호한 기준**:
- SaaS/구독: 월 2~3% 이하
- B2B: 월 1% 이하
