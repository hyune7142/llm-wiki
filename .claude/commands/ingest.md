새 소스를 위키에 추가(ingest)합니다.

**진행 방식 (Claude에게)**:

사용자가 `/ingest` 를 실행하면:

1. `raw/` 폴더 안의 파일 목록을 확인한다.
2. 아직 위키에 등록되지 않은 파일(`wiki/log.md`에 ingest 기록이 없는 것)이 있으면 목록을 보여주고 어떤 파일을 처리할지 물어본다.
3. 사용자가 파일을 선택하면(또는 `/ingest raw/파일명.md` 형태로 직접 지정하면) 아래 순서로 처리한다:

**처리 순서**:

1. **읽기**: 소스 파일을 읽는다. 이미지가 포함되어 있으면 이미지도 함께 확인한다.
2. **논의**: 핵심 내용 2~3가지를 짧게 요약해서 사용자에게 보여주고, 특별히 강조하거나 주목할 부분이 있는지 물어본다.
3. **소스 페이지 작성**: `wiki/` 에 소스 요약 페이지를 만든다.
   - 파일명: `wiki/source-[소스제목-슬러그].md`
   - 프론트매터 포함 (`type: source`, `sources`, `updated` 등)
   - 요약, 핵심 주장, 주요 인용, 관련 개념/개체 링크 포함
4. **기존 페이지 업데이트**: `wiki/index.md`를 읽고 관련 entity / concept 페이지를 찾아 내용을 보완하거나 새로 생성한다. 한 소스가 여러 페이지에 영향을 줄 수 있다.
5. **인덱스 업데이트**: `wiki/index.md`에 새 페이지들을 등록한다.
6. **로그 기록**: `wiki/log.md`에 항목 추가.
   - 형식: `## [YYYY-MM-DD] ingest | [소스 제목]`
   - 내용: 생성/수정된 페이지 목록, 핵심 인사이트 한 줄 요약

처리가 끝나면 생성·수정된 페이지 목록을 사용자에게 보여준다.
