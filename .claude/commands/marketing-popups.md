이메일 수집, 전환, 이탈 방지 등 다양한 목적의 팝업 문구를 작성합니다.

**시작 전 확인사항**:

1. **팝업 유형**: 이메일 수집? 이탈 방지? 프로모션?
2. **목적**: 가입? 다운로드? 구매? 유지?
3. **타겟 방문자**: 신규 방문자? 특정 페이지 방문자?
4. **제공할 것**: 할인? 무료 자료? 알림 신청?

## 팝업 유형별 가이드

### 이메일 수집 팝업

```
헤드라인:  [원하는 결과]를 원하시나요?
서브텍스트: [구체적인 혜택] — [얼마나 자주/어떤 형태]
이메일 입력 필드
CTA 버튼: [구체적인 행동 동사]
닫기 텍스트: "괜찮아요, 필요 없어요"
```

**예시**:
```
헤드라인:  마케팅 인사이트를 받아보세요
서브텍스트: 매주 실무에 바로 쓸 수 있는 팁 3가지
버튼: 무료로 구독하기
닫기: 아니요, 혼자 할게요
```

### 이탈 방지 팝업 (Exit Intent)

```
헤드라인:  잠깐만요!
서브텍스트: 떠나기 전에 [할인/혜택] 받아가세요
CTA: [혜택] 받기
```

### 프로모션 팝업

```
헤드라인:  [기간 한정 / 특별 혜택]
서브텍스트: [구체적인 혜택] — [마감 기한]
CTA: 지금 받기
닫기: 놓칠게요
```

---

## 팝업 카피 원칙

**헤드라인**: 방문자가 무엇을 얻는지 즉시 전달

**반전 CTA (닫기 버튼)**:
- "아니요, 저는 [손해를 감수할게요]"
- 예: "아니요, 매출이 올라도 괜찮아요"
- 과도하면 역효과 — 적절한 수준 유지

**입력 필드 최소화**:
- 이메일만 받는 것이 전환율 최고

## 타이밍 설정 가이드

| 타이밍 | 적합한 팝업 |
|--------|------------|
| 입장 즉시 | 비추천 (높은 거부감) |
| 5~10초 후 | 웰컴 오퍼 |
| 스크롤 50~70% | 콘텐츠 관심자 대상 |
| 이탈 시 | 마지막 기회 오퍼 |
