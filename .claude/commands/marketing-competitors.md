경쟁사와 비교하는 마케팅 콘텐츠를 작성합니다.

**시작 전 확인사항**:

1. **비교 대상**: 어떤 경쟁사와 비교할 것인가?
2. **페이지 유형**: "[우리] vs [경쟁사]" 페이지? "[경쟁사] 대안" 페이지?
3. **우리의 강점**: 어떤 점에서 유리한가?
4. **타겟**: 어떤 고객이 이 페이지를 볼 것인가?

---

## 비교 페이지 유형

### "A vs B" 페이지

두 제품을 공정하게 비교하는 것처럼 보이지만, 우리가 우세한 영역을 강조한다.

**SEO 가치**: "[우리제품] vs [경쟁사]" 키워드 — 구매 고려 단계 검색

### "[경쟁사] 대안" 페이지

경쟁사에 불만족한 고객을 직접 타겟.

**SEO 가치**: "[경쟁사] 대안", "[경쟁사] 갈아탈 곳" 키워드

---

## 비교 페이지 작성 원칙

**공정하게 보여야 한다**
- 경쟁사를 비방하면 역효과
- 경쟁사가 잘하는 것도 솔직하게 인정
- 우리가 맞지 않는 고객도 명시

**우리가 이기는 영역에 집중**
- 모든 기능을 비교하면 묻힌다
- 핵심 차별점 3가지만 강하게

**고객 언어 사용**
- "경쟁사에서 넘어온 고객이 자주 말하는 것들"로 구성

---

## "A vs B" 페이지 구조

```
헤드라인: [우리] vs [경쟁사] — 차이를 알고 선택하세요

TL;DR 요약 (간단 비교표)

핵심 차이점 1
핵심 차이점 2
핵심 차이점 3

상세 기능 비교표

고객 인용 (경쟁사에서 넘어온)

[우리]가 더 맞는 사람
[경쟁사]가 더 맞는 사람

CTA — 무료 체험 또는 비교 데모
```

---

## 비교표 작성 가이드

```
| 기능/항목 | [우리] | [경쟁사] |
|-----------|--------|---------|
| [중요 항목] | ✅ | ❌ |
| [중요 항목] | ✅ | 제한적 |
| [경쟁사 강점 항목] | 기본 지원 | ✅ |
```

**규칙**:
- 우리가 강한 항목을 위에 배치
- 경쟁사 강점도 1~2개 포함 (공정성 인상)
- "있음/없음"보다 구체적으로

## "[경쟁사] 대안" 페이지 구조

```
헤드라인: [경쟁사]를 떠나고 싶다면 — [우리]가 있습니다

[경쟁사]에서 자주 듣는 불만들
(고객 리뷰에서 실제 인용)

왜 사람들이 [우리]로 넘어오는가

[우리]가 다른 점 3가지

전환 지원 (데이터 이전 등)

소셜 프루프 (전환한 고객 사례)

CTA
```
