데이터를 활용해 수십~수천 개의 SEO 최적화 페이지를 체계적으로 생성합니다.

**시작 전 확인사항**:

1. **비즈니스 유형**: 어떤 종류의 페이지가 필요한가?
2. **보유 데이터**: 어떤 데이터로 페이지를 만들 것인가?
3. **타겟 키워드 패턴**: 어떤 검색어 패턴을 노리는가?
4. **기술 스택**: 웹사이트가 어떤 플랫폼인가?

## 프로그래매틱 SEO란

하나하나 손으로 쓰는 대신, 데이터 구조 + 템플릿을 활용해 대량의 페이지를 만드는 방법.

**예시**:
- "[도시명] + [서비스명]" 지역 페이지 → 전국 100개 도시 × 50개 서비스 = 5,000개 페이지
- "[A] vs [B]" 비교 페이지 → 10개 제품 중 2개씩 조합 = 45개 비교 페이지
- "[도구명] 사용법" → 업계 도구 200개 페이지

---

## 적합한 활용 사례

| 유형 | 예시 |
|------|------|
| 지역 기반 | "[지역명] 마케팅 대행사" |
| 카테고리 기반 | "[업종별] 마케팅 전략" |
| 비교 페이지 | "[도구A] vs [도구B]" |
| 통합/연동 | "[소프트웨어A] + [소프트웨어B] 연동" |
| 직업/역할 기반 | "[직책]을 위한 [솔루션]" |
| 롱테일 키워드 | "어떻게 [X]를 하는가" 변형 수백 개 |

## 핵심 원칙

**양보다 질 — 얇은 콘텐츠 금지**

구글은 가치 없는 대량 페이지를 페널티. 각 페이지가 독립적인 가치를 가져야 한다.

**각 페이지가 달라야 한다**
- 단순히 단어만 바꾼 동일 페이지 금지
- 각 변수에 맞는 고유 데이터/콘텐츠 필요

---

## 실행 단계

### 1단계: 키워드 패턴 발굴

```
[수식어] + [핵심 키워드] + [수식어]
예:
- [지역] + [서비스]
- [업종] + [문제]
- [제품A] vs [제품B]
```

### 2단계: 데이터 준비

- 각 페이지에 필요한 고유 데이터 수집
- 스프레드시트 또는 데이터베이스로 구조화

### 3단계: 페이지 템플릿 설계

```
[변수1]를 위한 [변수2] 완벽 가이드

## [변수1]에서 [변수2]가 필요한 이유
[데이터 기반 고유 내용]

## [변수1] 특화 [변수2] 전략
[각 변수에 맞는 구체적 내용]

## 자주 하는 질문
[변수별 FAQ]
```

### 4단계: 품질 검증

- 샘플 20~30개 페이지 직접 검토
- 실제 가치 있는 내용인지 확인
- 구글 Search Console로 인덱싱 모니터링
