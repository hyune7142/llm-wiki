## 시작 전: 제품 마케팅 컨텍스트 확인

`.claude/product-marketing.md`가 있으면 먼저 읽고 시작한다. 이미 파악된 제품/고객/포지셔닝 정보는 다시 묻지 않는다. 파일이 없으면 `/marketing-product-marketing` 먼저 실행 권장.

---
각 광고 플랫폼에 맞는 광고 문구와 크리에이티브를 제작합니다.

**시작 전 확인사항**:

1. **플랫폼**: 구글, 메타(인스타/페이스북), 링크드인, 유튜브, 틱톡
2. **타겟 고객**: 누구에게 보여줄 것인가?
3. **제품/서비스**: 핵심 가치, 차별점
4. **목표**: 클릭? 전환? 인지도?
5. **기존 광고 성과**: 잘 된 것, 안 된 것 (있으면)

## 핵심 원칙

**구체적이고 측정 가능한 표현 사용**
- "빠른 처리" → "48시간 내 응답"
- "많은 고객" → "누적 1,200개 기업"

**혜택 먼저, 기능은 나중에**
- 기능: "AI 분석 엔진"
- 혜택: "보고서 작성 시간 80% 단축"

**강력한 CTA**
- "더 알아보기" → "무료로 시작하기"
- "문의하기" → "30초 만에 견적 받기"

## 플랫폼별 제한 및 가이드

### 구글 검색광고 (RSA)

| 항목 | 제한 |
|------|------|
| 헤드라인 | 최대 15개, 각 30자 이내 |
| 설명문 | 최대 4개, 각 90자 이내 |

**헤드라인 유형**:
- 키워드 포함 (검색 의도 매칭)
- 핵심 혜택 강조
- 소셜 프루프 ("고객 1,000+ 사용")
- CTA ("지금 무료 체험")
- 차별점 ("경쟁사 대비 2배 빠름")

### 메타(페이스북/인스타그램)

| 항목 | 권장 길이 |
|------|-----------|
| 본문 | 125자 (접힘 전) |
| 헤드라인 | 40자 이내 |
| 설명 | 30자 이내 |

**광고 구조 공식**:
- **PAS**: 문제 → 자극 → 해결책
- **BAB**: 현재 상황 → 달라진 모습 → 어떻게 달라지는가
- **AIDA**: 주목 → 흥미 → 욕구 → 행동

### 링크드인

| 항목 | 권장 길이 |
|------|-----------|
| 소개 문구 | 150자 이내 (접힘 전) |
| 헤드라인 | 70자 이내 |

- B2B, 직책/업종 타겟팅에 강함
- 전문적 톤 유지
- 데이터/사례 활용

## 광고 변형 생성 방법

같은 광고를 여러 각도로 변형해 테스트한다:

**각도 1: 혜택 중심**
"[결과]를 [시간] 안에 달성하세요"

**각도 2: 문제 중심**
"[불편함]에 지치셨나요? [솔루션]이 있습니다"

**각도 3: 사회적 증거**
"[N]개 기업이 이미 선택한 [카테고리]"

**각도 4: 비교**
"[경쟁 방식] 대신 [우리 방식]으로"

**각도 5: 긴급성/희소성**
"[기간] 한정 — [혜택]"

## 이미지/영상 가이드

**이미지 광고**:
- 실제 제품 UI (허위 연출 금지)
- 실제 사람 얼굴 (스톡 이미지보다 효과 높음)
- 전후 비교
- 텍스트 최소화 (이미지의 20% 이하)

**영상 광고 (15~30초)**:
- 0~3초: 훅 (스크롤 멈추게)
- 3~10초: 문제 또는 흥미 유발
- 10~25초: 해결책 보여주기
- 25~30초: CTA
