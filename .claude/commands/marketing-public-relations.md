## 시작 전: 제품 마케팅 컨텍스트 확인

`.claude/product-marketing.md`가 있으면 먼저 읽고 시작한다. 이미 파악된 제품/고객/포지셔닝 정보는 다시 묻지 않는다. 파일이 없으면 `/marketing-product-marketing` 먼저 실행 권장.

---
언론 홍보와 미디어 전략을 수립합니다.

**핵심 원칙**: PR은 배포(Distribution)의 대체재가 아니다. 증폭기다. 언론 노출이 나면 바로 이메일, SNS 등 자체 채널로 추가 확산해야 한다.

**시작 전 확인사항**:

1. **PR 목표**: 브랜드 인지도? 신뢰도? 투자자 유치? 채용?
2. **대상 미디어**: 어떤 매체에 나고 싶은가? (업종지, 일간지, 유튜브, 팟캐스트 등)
3. **뉴스 소재**: 지금 가진 스토리는 무엇인가?
4. **보도 자료 필요 여부**: 있는가? 없는가?

---

## PR 4가지 모드

| 모드 | 특징 | 소요 기간 |
|------|------|-----------|
| **뉴스재킹 (Newsjacking)** | 현재 이슈에 올라타기 | 몇 시간~며칠 |
| **적극적 피칭** | 기자에게 먼저 스토리 제안 | 2~8주 |
| **인바운드 요청 대응** | 기자가 먼저 연락 왔을 때 | 즉시 |
| **소유 미디어** | 보도자료, 미디어킷, 공식 채용 | 상시 |

## 좋은 PR 피치의 조건

피치 보내기 전 체크:

- [ ] 이 기자가 실제 이 주제를 커버하는가?
- [ ] 명확한 뉴스 훅이 있는가? (왜 지금인가?)
- [ ] 피치 자체로 완결성이 있는가? (첨부 없이도 이해 가능)
- [ ] 150단어 이내인가?
- [ ] 제목이 구체적인가? (홍보성 제목 금지)
- [ ] CTA가 명확한가? (인터뷰 요청? 자료 제공?)

---

## 피치 구조

```
제목: [구체적인 스토리/데이터 포인트] (뉴스성 있게)

안녕하세요 [기자 이름]님,

[기자의 최근 기사 또는 관심사 언급 1문장]

[우리의 뉴스/스토리를 1~2문장으로] 

[독자에게 왜 중요한가 1문장]

[구체적인 요청: "15분 인터뷰 가능하신지요?" 또는 "더 자세한 자료를 보내드릴까요?"]

[이름, 직함, 연락처]
```

---

## 뉴스 소재 발굴

**우리가 가진 스토리**:
- 사용자/고객 수 이정표 달성
- 새 제품/기능 출시
- 파트너십 또는 투자 유치
- 업계 데이터/리서치 발표
- 창업자 스토리

**뉴스재킹 기회**:
- 업계 큰 이슈 발생 → 우리 시각 또는 데이터 제공
- 계절성 이슈 (연말, 신학기, 트렌드)
- 경쟁사의 나쁜 뉴스 → 우리 차별점 부각

## 보도자료 구조

```
[즉시 배포 가능]
날짜

제목: [명확하게, 뉴스성 있게]
부제: [보완 정보]

[도시명] — [핵심 정보를 1~2문장으로. 5W1H 포함]

[상세 내용 1~2 단락]

[인용구: "대표 이름": "의미 있는 발언"]

[회사 소개 (Boilerplate) — 3~4문장]

[미디어 연락처]
이름 / 직함 / 이메일 / 전화
```

## 성과 측정

| 지표 | 측정 방법 |
|------|-----------|
| 게재 수 | 실제 기사/영상 수 |
| 미디어 품질 | 매체 규모, 타겟 적합도 |
| 레퍼럴 트래픽 | UTM 또는 GA4 |
| 브랜드 검색량 증가 | 네이버 트렌드, 구글 트렌드 |
