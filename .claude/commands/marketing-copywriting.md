전환을 높이는 마케팅 카피를 작성합니다.

**시작 전 확인사항**:

카피 작성 전 아래 정보를 파악한다. 이미 제공된 정보는 다시 묻지 않는다.

1. **어떤 페이지/매체인가?** (홈페이지, 랜딩페이지, 광고, SNS 등)
2. **타겟 고객은 누구인가?** (업종, 역할, 규모, 주요 고민)
3. **핵심 가치 제안은 무엇인가?** (경쟁사 대비 차별점)
4. **고객이 현재 느끼는 가장 큰 불편함은?**
5. **원하는 톤은?** (전문적, 친근한, 직설적, 감성적 등)

## 카피라이팅 핵심 원칙

**명확함이 창의성보다 먼저다**
- 멋진 표현보다 고객이 즉시 이해하는 문장을 쓴다
- "혁신적인 솔루션"보다 "3분 안에 견적서 자동 생성"이 낫다

**기능이 아닌 결과를 쓴다**
- 기능: "AI 기반 분석 엔진 탑재"
- 결과: "보고서 작성 시간을 3시간에서 10분으로"

**구체적인 숫자를 쓴다**
- "빠른 처리" → "평균 2.3초 응답"
- "많은 고객" → "누적 1,200개 기업 사용"

**고객의 언어를 쓴다**
- 내부 용어, 업계 전문어보다 고객이 실제 말하는 단어 사용
- 고객 리뷰, 인터뷰에서 나온 표현 그대로 활용

**금지 표현**
- 감탄부호 남발 (!)
- 수동태 ("제공됩니다", "확인되었습니다")
- 공허한 수식어 ("최고의", "혁신적인", "스마트한")
- 근거 없는 주장 ("업계 1위", "독보적인")

## 페이지별 구조

### 홈페이지 / 랜딩페이지

```
헤드라인       — 누구를 위해 무엇을 해주는가 (10단어 이내)
서브헤드라인   — 헤드라인 보완, 차별점 추가
CTA 버튼       — 동작 동사 + 구체적 결과 ("무료로 시작하기", "견적 받기")
소셜 프루프    — 고객 수, 리뷰 평점, 언론 노출
문제 제시      — 고객이 지금 겪는 상황
해결책         — 제품/서비스가 어떻게 해결하는지
작동 방식      — 3단계 이내로 간결하게
반론 처리      — 주요 구매 망설임 사유 해소
최종 CTA       — 다시 한번 행동 유도
```

### 광고 카피 (배너, SNS 광고)

- 첫 문장에서 타겟 고객을 특정한다 ("팀장급 마케터라면")
- 고통 → 해결 → 증거 → 행동 순서
- 모바일 기준 3초 안에 핵심 전달

### 이메일 제목

- 30자 이내
- 호기심형: "[이름]이 이걸 묻더라구요"
- 직접형: "이번 달 매출 보고서 자동화하는 법"
- 숫자형: "영업팀이 쓰는 5가지 템플릿"

## 작성 후 체크리스트

- [ ] 타겟 고객이 읽었을 때 "이거 나 얘기네"라는 느낌이 드는가?
- [ ] 첫 문장만 읽어도 뭘 파는지 알 수 있는가?
- [ ] 기능이 아닌 결과로 설명했는가?
- [ ] 구체적인 숫자나 증거가 있는가?
- [ ] 다음 행동이 명확한가?
