# Report 디렉토리

이 디렉토리는 **위키 쿼리 결과물을 독립 문서로 보존**하기 위한 공간입니다.

## 목적

`wiki/`가 지식을 축적하고 유지하는 내부 저장소라면,  
`report/`는 **사용자가 직접 활용할 수 있는 결과물**을 저장하는 외부 출력 공간입니다.

- 리포트는 위키 링크(`[[...]]`) 없이 독립적으로 읽힐 수 있도록 작성됩니다.
- 위키가 업데이트되어도 리포트는 생성 시점의 내용을 그대로 유지합니다 (스냅샷).
- 공유, 발표, 보고서 작성 등 외부 활용을 위해 사용합니다.

## 파일 명명 규칙

```
report/YYYY-MM-DD-[주제-슬러그].md
```

예시:
- `report/2026-05-14-집중투표제-현황.md`
- `report/2026-05-14-agm-주요변화-비교.md`

## 리포트 생성 방법

1. `/query`로 질문하고 답변을 받은 뒤, 마지막에 "리포트로 저장할까요?" 질문에 **네** 응답
2. 또는 `/report`를 직접 실행하여 리포트 주제와 형식을 지정

## wiki/ 와의 차이

| | wiki/ | report/ |
|---|---|---|
| 목적 | 지식 축적 및 연결 | 결과물 출력 및 공유 |
| 업데이트 | 지속적으로 갱신 | 생성 시점 고정 (스냅샷) |
| 링크 | `[[위키링크]]` 사용 | 독립 문서 (링크 없음) |
| 대상 | Claude가 내부 참조 | 사용자가 외부 활용 |
