# LLM Wiki

Claude Code로 굴리는 개인 지식 위키 템플릿이에요.

읽은 글, 논문, 메모 같은 걸 `raw/` 폴더에 던져두면 Claude가 읽고 정리해서 위키를 만들어줍니다. 직접 정리할 필요 없고 그냥 "이거 처리해줘" 하면 돼요. 그 다음부턴 질문하면서 쌓인 위키를 탐색하는 게 전부입니다.

---

## 시작하는 방법

**1. 레포 클론 후 Obsidian으로 열기**

```bash
git clone <레포 URL>
```

Obsidian에서 `Open folder as vault`로 열면 나중에 그래프 뷰로 위키 연결 구조를 볼 수 있어요.

**2. Claude Code 실행**

```bash
claude
```

**3. 초기 설정**

```
/wiki-init
```

Claude가 몇 가지 질문을 하나씩 물어보면서 설정을 잡아줍니다. 5분이면 끝나요.

**4. 첫 소스 추가**

`raw/` 폴더에 파일 넣고 Claude한테 말하면 됩니다.

> "raw/파일명.md 처리해줘"

---

## 사용 가능한 커맨드

### 위키 운영

| 커맨드 | 설명 |
|---|---|
| `/wiki-init` | 처음 설정할 때. 위키 이름·도메인·목적 등을 질문해서 CLAUDE.md를 자동 업데이트 |
| `/ingest` | 새 소스 추가. `raw/` 폴더의 미처리 파일을 감지해서 위키 페이지로 변환 |
| `/query` | 위키 기반 질문 답변. 관련 페이지를 읽고 출처를 명시해서 답변 |
| `/lint` | 위키 전체 점검. 모순·고아 페이지·누락 링크 등을 보고하고 개선 제안 |

### Obsidian 작성 보조

| 커맨드                  | 설명                                                                                        |
| -------------------- | ----------------------------------------------------------------------------------------- |
| `/obsidian-markdown` | Obsidian 전용 마크다운 문법 가이드. `[[위키링크]]`, 콜아웃, 임베드, frontmatter 등을 정확히 작성할 때 자동 적용             |
| `/defuddle`          | URL에서 광고·네비게이션을 제거하고 깔끔한 마크다운을 추출. 웹 아티클을 `raw/`에 저장할 때 유용 (`npm install -g defuddle` 필요) |
|                      |                                                                                           |

## 폴더 구조

```
/
├── raw/          ← 원본 소스 넣는 곳 (Claude가 읽기만 함)
│   └── assets/   ← 이미지 등
├── wiki/         ← Claude가 만들고 관리하는 위키 페이지들
│   ├── index.md  ← 전체 목차
│   └── log.md    ← 작업 기록
├── CLAUDE.md     ← Claude한테 위키 운영 방식 알려주는 설정 파일
└── README.md
```

## 몇 가지 팁

- **[Obsidian Web Clipper](https://obsidian.md/clipper)** 설치하면 브라우저에서 아티클을 바로 마크다운으로 저장할 수 있어서 편해요.
- 위키가 좀 쌓이면 Obsidian 그래프 뷰에서 보는 게 꽤 재밌습니다. 어떤 개념이 허브가 되는지 한눈에 보여요.
- 그냥 마크다운 파일 모음이라 git이 그대로 됩니다. 버전 관리, 브랜치, 협업 다 가능해요.
- Claude랑 대화하다가 좋은 분석이 나왔으면 버리지 말고 "이거 위키에 저장해줘" 해두세요. 나중에 또 쓸 수 있어요.

---

## 왜 RAG랑 다른가요

ChatGPT나 NotebookLM에 파일 올리는 것처럼 매번 원본 문서를 뒤지는 방식이 아니에요. 소스를 한 번 읽고 위키를 만들어두면, 다음 질문부터는 이미 정리된 위키를 보고 답해줍니다. 소스가 쌓일수록 위키도 같이 풍부해지는 구조예요.

자세한 배경이 궁금하면 원본 아이디어 문서를 참고해보세요.
